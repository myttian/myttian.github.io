# Windows环境变量

### 核心用户目录变量

- ‌**`%USERPROFILE%`**‌：当前用户的配置文件根目录，对应 `C:\Users\你的用户名`，存放桌面、文档、下载等个人文件。
- ‌**`%HOMEPATH%`**‌：同样是用户目录路径，通常与 `%USERPROFILE%` 一致，但只返回路径后半段（如 `\Users\你的用户名`）。
- ‌**`%HOMEDRIVE%`**‌：用户目录所在的盘符，一般是 `C:`。
- ‌**`%USERNAME%`**‌：当前登录的账户名。

### 用户目录下的常用子目录变量

- ‌**`%APPDATA%`**‌：漫游应用数据目录，即 `C:\Users\你的用户名\AppData\Roaming`，存软件配置、聊天记录等。
- ‌**`%LOCALAPPDATA%`**‌：本地应用数据目录，即 `C:\Users\你的用户名\AppData\Local`，存缓存、临时文件等。
- ‌**`%TEMP%`**‌ 或 ‌**`%TMP%`**‌：当前用户的临时文件目录，通常在 `%LOCALAPPDATA%\Temp`
