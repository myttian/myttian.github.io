## 图形API

Vulkan、OpenGL 和 DirectX 都是图形 API，作用是==充当 CPU 与 GPU 之间的“翻译工具”，让程序能调用显卡渲染画面==。

三者的核心区别在于平台支持、控制粒度和性能上限：`DirectX`由微软主导，主要绑定Windows/Xbox生态；`OpenGL`和`Vulkan`由Khronos 组织维护，支持Windows、Linux、Android等跨平台环境

其中 Vulkan 是 OpenGL 的现代化继任者，性能更高但开发更复杂。

### 三者分别是什么，由谁维护

- DirectX：微软开发的闭源图形 API，核心版本为 DirectX 12，专为Windows 和 Xbox平台优化，工具链成熟，广泛用于 3A 游戏和专业图形应用。
- OpenGL：Khronos 组织维护的开源跨平台图形 API，历史悠久，上手简单、兼容性强，但架构偏老，性能优化空间有限，目前逐渐被 Vulkan 取代。
- Vulkan：Khronos 组织推出的现代化底层图形 API，作为 OpenGL 的下一代标准，提供显式资源管理和低驱动开销，性能上限高，适合跨平台高性能渲染。


### 技术架构和性能有什么不同

- 控制方式：OpenGL 采用隐式状态机，驱动自动管理资源，开发简单但开销大；Vulkan 和 DirectX 12 采用显式架构，开发者需手动管理内存、命令队列和同步，代码量增加但能精细优化多线程性能。
- 性能表现：Vulkan 和 DirectX 12 因减少驱动开销、提升多核 CPU 利用率，在高负载场景下帧率通常比 OpenGL 高20% 至 100%；OpenGL 适合轻量应用或老项目维护，复杂场景性能受限。
- 学习成本：OpenGL 入门门槛低，适合教学和工具开发；Vulkan 和 DirectX 12 初始化流程长、概念多（如管线状态、描述符集），适合有经验的引擎开发者。

### 平台支持和怎么选

1. 平台兼容性：DirectX 仅支持Windows/Xbox；OpenGL 支持Windows、Linux、macOS、Android、iOS（但 macOS 逐步弃用）；Vulkan 原生支持Windows、Linux、Android，苹果生态需通过 MoltenVK 映射到 Metal。
2. 选型建议：
   - Windows 高性能游戏/专业应用：优先选 DirectX 12，生态和工具最完善。
   - 跨平台高端游戏/图形引擎：选 Vulkan，兼顾性能与多系统兼容。
   - 入门学习/老项目维护：OpenGL 仍可用，但新项目建议转向 Vulkan。
   - 苹果生态应用：必须使用 Metal，OpenGL 已不再推荐。

选型建议里提到了一些细节，要不要看看 Vulkan 在 macOS 上怎么用？ 或者 OpenGL 为什么性能不如 Vulkan？

## 视觉库和图形API

[图形相关的库](https://blog.csdn.net/qq_36831368/article/details/144172454)  [Google Vision API进行计算机视觉图像创意分析](https://zhuanlan.zhihu.com/p/621436653)  [DeepSeek V4 Flash 视觉模型实战：从 API 调用到本地部署](https://blog.csdn.net/weixin_29051193/article/details/170439001)  

[ 图像API](https://www.cnblogs.com/anesu/p/15769414.html)  [图形可视化 API](https://developer.aliyun.com/article/936761)   

“视觉库”和“图形API”不是一回事，但两者常配合使用。

图形API是底层“翻译官”，负责把渲染指令转成GPU能执行的命令；视觉库则是==基于API或直接封装好功能的工具集==，偏应用层，帮你快速实现图像处理、识别或3D场景搭建。

### 图形API：底层渲染接口

图形API直接与显卡驱动打交道，决定画面如何被绘制。常见的有：

- OpenGL：跨平台老牌API，兼容性好，适合教学、科研可视化、轻量项目，但已基本停止迭代。
- DirectX（DX11/DX12）：微软自家标准，仅支持Windows/Xbox，是3A游戏主力，DX12性能更强、控制更底层。
- Vulkan：OpenGL的“升级版”，跨平台、低开销、多线程强，适合追求极致性能的游戏和仿真，但学习曲线陡。
- Metal：苹果生态专属，针对Apple Silicon深度优化，用于iOS/macOS高性能渲染。
- WebGPU/WebGL：浏览器端方案，WebGL基于OpenGL ES，WebGPU更现代、性能更接近原生，是WebGL的继任者。

### 视觉库：功能封装与工具集

视觉库更偏“拿来就能用”，按用途分几类：

1. **计算机视觉库**‌：以OpenCV为代表，跨平台、性能好，提供图像读写、几何变换、特征点检测、人脸识别等API，适合做图像处理和分析；配合scikit-image、PyTorch、MediaPipe可覆盖从传统算法到深度学习的完整链路。‌‌

2. ‌**3D渲染与场景图库**‌：如OpenSceneGraph（OSG）擅长大规模地形和仿真可视化，VTK专攻科学数据体绘制和医学影像，OGRE材质系统强，适合游戏原型和精细渲染。‌‌
3. ‌**Web前端3D库**‌：如Three.js、Babylon.js、A-Frame，基于WebGL封装，浏览器里建3D场景简单，适合做展示和交互式应用。‌‌
4. ‌**科研绘图与学科专用工具**‌：如MindPlot做统计图表自动化，ChemDraw画化学结构式，MATLAB做算法仿真曲线，各有专业边界

### 两者怎么配合

典型关系是：上层视觉库或引擎调用底层图形API完成最终绘制。比如OSG基于OpenGL渲染，Unity引擎底层可切Vulkan或DX12；做医学可视化时，ITK处理影像数据、VTK做体绘制、OSG负责交互显示，最终都是通过图形API把像素画到屏幕上。

> 简单理解：图形API是“画布和画笔”的底层接口，视觉库是“颜料、模板和助手”，帮你更快画出想要的东西。选型时先看目标平台和性能需求，再决定用哪一层。

## OpenCV

[opencv_百度百科](https://baike.baidu.com/item/opencv/10320623)  [C++ OpenCV | 菜鸟教程](https://www.runoob.com/cplusplus/cpp-opencv.html)

OpenCV（Open Source Computer Vision Library）是同时采用 Apache 2.0 与 BSD 两种开源许可协议的跨平台计算机视觉库，2000 年 6 月首次发布，支持 Linux、Windows、Android 及 Mac OS 等操作系统，提供 C、Python、Java 等多语言接口 。

官方链接：[https://opencv.org/](https://opencv.org/)（OpenCV 官方网站，提供下载、文档及社区资源）

### 核心功能与版本信息

1. 主要功能模块：涵盖图像处理、运动跟踪、人脸检测、目标检测、视频分析等核心功能，通过标准化 API 集成机器学习算法与深度学习框架模型 。

2. 最新版本：根据 InfoWorld 2026 年 9 月信息，OpenCV 5.0 为当前最新版本，进行了 API 结构现代化重构，更好兼容机器学习工作流 。
3. 性能优化：核心代码采用 C++ 编写并针对实时视觉应用优化，可利用 MMX 和 SSE 指令提升性能，支持 GPU 加速及 ONNX 模型部署 。


### 学习资源与获取方式

1. 代码仓库：[https://github.com/opencv/opencv](https://github.com/opencv/opencv)（GitHub 官方仓库，含源码及 Issue 追踪）。
2. Python 快速安装：使用 pip 命令`pip install opencv-python`即可安装核心库，如需扩展功能（如 SIFT 算法）可安装`opencv-contrib-python`。
3. 官方文档：官网提供多语言教程、API 参考及示例代码，建议从实际项目需求出发逐步扩展功能模块 。

### 使用提示

- 请认准官方域名 opencv.org 及 GitHub 官方仓库，避免下载山寨版本或含恶意代码的第三方包。
- 商业应用与非商业应用均免费，但需遵守 Apache 2.0 与 BSD 开源协议条款 。
- 跨平台部署时注意依赖库兼容性，Linux 环境下需确保 libopencv_dnn.so 等动态库正确加载 。
