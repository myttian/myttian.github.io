# 机器学习和深度学习

[机器学习 VS. 深度学习](https://zhuanlan.zhihu.com/p/26769864)  

==深度学习是机器学习的子集==，两者都属于人工智能领域，核心区别在于==深度学习用多层神经网络自动提取特征，而传统机器学习需要人工设计特征== 。

### 两者有啥核心区别

1. 特征处理方式不同：传统机器学习需要工程师手动选择和设计特征，比如识别垃圾邮件时要人工指定关键词、发件人等特征 ；深度学习则通过多层神经网络自动从数据中学习特征，减少人工干预 。
2. 数据需求量不同：机器学习在中小规模结构化数据上就能出效果，深度学习需要大规模非结构化数据才能发挥优势 。
3. 计算资源要求不同：机器学习普通 CPU 即可运行，深度学习需要 GPU 加速计算来处理大量矩阵运算 。
4. 可解释性不同：机器学习算法如决策树能清楚解释每一步选择的原因，深度学习是"黑箱"模型，难以解释具体决策过程 。


### 都用在哪类场景

1. 机器学习常见应用：
   - 预测分析、推荐系统、客户细分。
   - 金融风控、欺诈检测、信用评估。
   - 时间序列分析、异常检测。
2. 深度学习常见应用：
   - 图像识别、人脸识别、车牌号识别。
   - 语音识别、自然语言处理、机器翻译。
   - 自动驾驶、视频游戏 AI、短视频推荐。
3. 两者互补使用：在某些场景下会结合使用，如图像识别领域深度学习是主流，但时间序列分析等传统机器学习算法仍有不可替代的优势 。


### 深度学习咋工作的

1. 模拟人脑神经网络：深度学习灵感来源于人类大脑神经系统，通过多层节点连接和权重调整来处理信息 。
2. 分层提取特征：以识别猫狗图片为例，底层先学习边和直线等低层特征，中间层学习面部部分特征，高层最终确定哪些特征对识别起重要作用 。
3. 端到端学习：输入原始数据后直接输出最终结果，让网络自己学习如何提取关键特征，无需人工分步处理 。
4. 2024 年诺贝尔奖认可：约翰·霍普菲尔德和杰弗里·辛顿因使用人工神经网络进行机器学习的基础性发现和发明获得诺贝尔物理学奖，印证了该领域的重要性 。
