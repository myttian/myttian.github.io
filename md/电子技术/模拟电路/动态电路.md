# 动态电路

这两个概念是电路分析的两条主线，区别不在于“难与易”，而在于**你关心的是哪一段时间、哪一部分响应**。

### 一句话区分

- **稳态分析**：电路已经“安定”下来，响应与激励保持固定的函数形式（直流是常数，正弦是同频率正弦），只关心这个最终形态。
- **暂态分析**：研究换路（开关动作、激励突变）之后到进入稳态之前这段过渡过程，响应包含随时间衰减的自由分量。

数学上的对应关系是：

$\text{全响应} = \text{强制分量（稳态解）} + \text{自由分量（暂态解）}$

==强制分量由激励决定，自由分量由电路结构和元件参数决定（特征根）==，并随时间按指数衰减到零。所以**暂态过程结束后，剩下的就是稳态**。

### 稳态分析

#### 直流稳态

电感、电容进入稳态后行为退化，这里正好接上你最早那条直觉：

| 元件 | 直流稳态等效 | 原因                                   |
| ---- | ------------ | -------------------------------------- |
| 电容 | **开路**     | 电压恒定，$i_C = C\frac{du_C}{dt} = 0$ |
| 电感 | **短路**     | 电流恒定，$u_L = L\frac{di_L}{dt} = 0$ |

注意这是“稳态下的等效”，不是元件被拿掉。此时电容可以带电压（开路但电压不为零），电感可以带电流（短路但电流不为零）。这两个值正是换路瞬间的**初始状态来源**。

#### 正弦稳态

激励是正弦量，稳态响应是同频率的正弦量，用**相量法**把微分方程变成代数方程：

- 元件关系：$R \to R$，$L \to j\omega L$，$C \to \frac{1}{j\omega C}$
- 分析手段：阻抗/导纳串并联、分压分流、节点法、网孔法、戴维南等效，全部照搬电阻电路的套路
- 额外要处理功率：$P = UI\cos\varphi$（有功）、$Q = UI\sin\varphi$（无功）、$S = \dot U \dot I^*$（复功率），以及最大功率传输、功率因数校正

正弦稳态里**没有衰减项**，因为假设已经过了无穷长时间，自由分量早已消失。

### 暂态分析

#### 起点：换路定则

储能元件的能量不能跃变，这是暂态分析的物理根基：

$u_C(0_+) = u_C(0_-), \qquad i_L(0_+) = i_L(0_-)$

求 $0_+$ 时刻其他量的步骤：先由 $0_-$ 电路（直流稳态等效）求出 $u_C(0_-)$、$i_L(0_-)$，再把电容换成电压源 $u_C(0_+)$、电感换成电流源 $i_L(0_+)$，得到 $0_+$ 等效电路，用纯电阻电路方法求其余变量。

这里有个高频错点：**电容电压和电感电流不能跃变，但电容电流、电感电压可以跃变**。所以“$u_C$ 连续”不代表整个电路都连续。

#### 一阶电路：三要素法

只含一个独立储能元件（或可等效为一个）时，任何电压/电流都满足

$f(t) = f(\infty) + \left[f(0_+) - f(\infty)\right]e^{-t/\tau}, \quad t \ge 0$

三个要素：

- $f(0_+)$：初始值，靠换路定则
- $f(\infty)$：稳态值，靠直流稳态等效（**这里就用上稳态分析了**）
- $\tau$：时间常数，$\tau = RC$ 或 $\tau = \dfrac{L}{R_{eq}}$，其中 $R_{eq}$ 是从储能元件两端看进去的戴维南等效电阻

三要素法本质就是“稳态 + 暂态”的显式表达：$f(\infty)$ 是稳态分量，指数项是暂态分量。工程上一般认为经过 $3\tau \sim 5\tau$ 暂态基本结束。

#### 二阶电路：阻尼状态

含两个独立储能元件（如 RLC 串联/并联），列二阶微分方程，特征根决定形态。以串联 RLC 为例：

$\alpha = \frac{R}{2L}, \quad \omega_0 = \frac{1}{\sqrt{LC}}, \quad \zeta = \frac{\alpha}{\omega_0}$

| 条件            | 名称     | 响应形态                                                  |
| --------------- | -------- | --------------------------------------------------------- |
| $\zeta > 1$     | 过阻尼   | 两个负实根，单调衰减，不振荡                              |
| $\zeta = 1$     | 临界阻尼 | 重根，最快无振荡回到稳态                                  |
| $0 < \zeta < 1$ | 欠阻尼   | 共轭复根，衰减振荡，$\omega_d = \omega_0\sqrt{1-\zeta^2}$ |
| $\zeta = 0$     | 无阻尼   | 纯虚根，等幅振荡（理想 LC）                               |
| $\zeta < 0$     | 负阻尼   | 含受控源或负阻时可能出现，振幅发散                        |

最后一行和你上一轮问的**受控源**直接相关：含受控源的电路可能出现负电阻，使特征根实部为正，系统不稳定。这是稳态分析看不出来、只有暂态分析才能暴露的问题。

#### 求解方法的选择

- **经典法**：列微分方程，求齐次解 + 特解。物理意义最清楚。
- **三要素法**：仅限一阶，最快。
- **拉普拉斯变换法**：把初始条件直接嵌入运算电路（电容→$\frac{1}{sC}$ 串联 $u_C(0_-)/s$ 电压源，电感→$sL$ 并联 $i_L(0_-)$ 电流源），代数求解后反变换。适合复杂电路和多输入。
- **状态变量法**：以 $u_C$、$i_L$ 为一阶方程组，便于数值计算和多阶系统。

### 两者的联系与切换

几个关键的衔接点：

1. **稳态是暂态的终点**。三要素法里的 $f(\infty)$ 就是一次稳态计算。
2. **暂态的初始条件来自换路前的稳态**。$0_-$ 电路必须按稳态等效来画。
3. **正弦激励下的暂态**：全响应 = 正弦稳态分量 + 衰减指数分量。此时“稳态”是正弦的，不是直流的，自由分量仍由特征根决定。
4. **换路频繁时要小心**：如果开关动作周期与 $\tau$ 相当，电路可能永远进不了稳态（如开关电源、PWM 电路），这时必须做周期性稳态（周期边界条件）分析，不能套用直流稳态等效。

### 常见坑

- 换路瞬间把电容当短路或开路。除非已知 $u_C(0_-)=0$（电容未充电）或 $i_L(0_-)=0$，否则不能这么简化。
- 用 $0_-$ 的电路直接求 $0_+$ 的其他变量，忘了换元件模型。
- 时间常数里的 $R$ 用了电源内阻之外的错误电阻，必须是从储能元件端口看进去的 $R_{eq}$（独立源置零，受控源保留）。
- 叠加定理用于暂态时，只能对**同一电路结构**的不同激励叠加，且每次都要重新算初始条件；换路本身不能用叠加定理处理。
- 认为“暂态很短就可以忽略”。在电力系统的短路故障、电机的启动过程、数字电路的时序余量里，暂态恰恰是核心考察对象。
