# 受控电源

顺着刚才“电压为零看短路、电流为零看开路”的思路，受控源（也叫非独立源）是这套直觉最容易失效的地方，值得单独拎出来说。

### 它是什么

受控源的电压或电流不是自己定的，而是由电路中**另一处**的电压或电流决定。图形符号是菱形（独立源是圆形）。四种类型：

| 类型                | 输出 | 控制量 | 参数含义             |
| ------------------- | ---- | ------ | -------------------- |
| VCVS 电压控制电压源 | 电压 | 电压   | 电压增益 μ（无量纲） |
| CCVS 电流控制电压源 | 电压 | 电流   | 转移电阻 r（Ω）      |
| VCCS 电压控制电流源 | 电流 | 电压   | 转移电导 g（S）      |
| CCCS 电流控制电流源 | 电流 | 电流   | 电流增益 β（无量纲） |

它本质上是描述“耦合”的元件，晶体管、运放、变压器的线性模型都靠它搭建。

### 和独立源最要紧的三点区别

1. **受控源不是激励**。独立源是电路能量的“起点”，受控源只是把某处的信号搬运到另一处，本身不能凭空作为整个电路的驱动。
2. **叠加定理中受控源必须保留**。独立源逐个置零（电压源短路、电流源开路）时，受控源原样留着，它的控制量也跟着每次分量的变化而变。这是最高频的错点。
3. **功率可正可负**。受控源既可能发出功率也可能吸收功率，所以含受控源的一端口往往是有源网络，等效电阻甚至可能算出负值。

### 回到你上一轮那个判据

如果受控源的控制量恰好为零，那么它的输出为零：

- 受控**电压源**输出为零 → 数值上等价于**短路**（理想电压源取零就是短路）；
- 受控**电流源**输出为零 → 数值上等价于**开路**。

这个结论本身成立，但有个前提：**控制量必须同步为零**。危险在于，当控制量取自受控源自己所在的支路，或者取自一个“因为受控源为零才为零”的支路时，就会出现循环约束、0/0 或者解不唯一的情况。这时不能先“把它短路/开路”再算，必须老老实实列方程。

另外反过来说不成立：不能因为某处电压为零就断定那里是受控源短路，也不能因为电流为零就断定受控电流源开路——很可能只是控制量本身为零。

### 含受控源的一端口，等效电阻怎么求

不能用“独立源置零后做电阻串并联”，因为受控源还活着。标准做法：

- **外加电源法**：把内部独立源置零（受控源保留），在端口外加电压源 U，求出端口电流 I，则 R_eq = U/I；外加电流源求电压也行。
- **开路电压/短路电流法**：R_eq = U_oc / I_sc。

算出负值不用慌，那正是含受控源（如晶体管模型、负阻抗变换器）的正常表现。

### 列方程的套路

用节点电压法或网孔电流法时，把受控源**暂时当成独立源**列方程，再补一条“控制量方程”，把控制量用节点电压或网孔电流表示出来。方程数就补齐了。

注意：受控电压源如果直接接在两个独立节点之间，节点法会多出一个未知电流，通常引入该电流变量（改进节点法），或者干脆选它作为参考方向做网孔法。

### 几个容易踩的坑

- 控制量支路如果是开路（电流为零），受控源输出为零；控制量支路如果是短路（电压为零），受控源输出也为零。做题时先判断控制量是否被“断掉”很关键。
- 受控源不能随意“拿掉”“断开”或“短路”，除非已经证明其输出为零。
- 互易定理一般不适用于含受控源的网络，除非受控源满足特定对称条件。
- 受控源的控制量必须是电路中真实存在的变量，不能指定一个不存在的支路。

如果你正在做题，可以把具体电路发我，我帮你走一遍节点法或外加电源法的完整过程——受控源这块，跟着算一遍比看十条规则都管用。

# 电源有载工作、开路短路

## 额定功率60w是每小时吗

额定功率60W不是“每小时”的概念，它是指==电器正常工作时的瞬时功率==，即每秒钟消耗60焦耳的能量。而“每小时耗电量”是功率乘以时间的结果，60W电器连续工作1小时，耗电0.06度（即0.06千瓦时）。

简单说：瓦（W）是功率，度（kWh）是电量，两者通过时间联系起来。功率表示“干活有多猛”，电量表示“干了多久活”。

### 怎么算的

- 60W = 0.06kW（1kW = 1000W）
- 每小时耗电 = 0.06kW × 1h = 0.06度电 
- 公式：耗电量（度）= 功率（kW）× 时间（小时）

### 实际参考

- 60W灯泡或小风扇，开10小时才耗0.6度电，约3毛钱电费
- 若电器标“额定功率60W”，指正常工作时稳定在60W；实际耗电还受使用时长、档位、能效等因素影响。

> 1度电 = 1千瓦时 = 1000W电器工作1小时消耗的电量。
