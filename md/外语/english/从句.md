# 引导词

## 从句引导词分类

英语从句引导词（Subordinating Words）根据**从句的性质**主要分为三大类：名词性从句引导词、定语从句引导词和状语从句引导词。它们的语法功能各不相同，不能混用。

以下是详细的分类体系：

### 1. 名词性从句引导词

**功能**：引导主语、宾语、表语或同位语从句，在句中相当于一个“名词”。

| 分类         | 引导词                   | 语法特点与含义                                              |
| ------------ | ------------------------ | ----------------------------------------------------------- |
| **连词**     | that                     | 无实义，不充当成分，仅起连接作用（宾语从句中常可省略）      |
|              | whether / if             | 表示“是否”，不充当成分（if 通常不引导主语/表语/同位语从句） |
| **连接代词** | who / whom / whose       | 指人，在从句中作主语/宾语/定语                              |
|              | what / whatever          | 指物/事，意为“所...的”，在从句中作主/宾/表语                |
|              | which / whichever        | 指特定范围内的“哪一个”                                      |
| **连接副词** | when / where / why / how | 分别表示时间/地点/原因/方式，在从句中作状语                 |

- **⚠️ 核心考点**：`that` 在名词性从句中**不作任何成分**；而 `what` 必须在从句中**充当主语、宾语或表语**。这是区分二者的关键。

### 2. 定语从句引导词（关系词）

**功能**：引导定语从句修饰先行词，既起连接作用，又在从句中**充当成分**。

| 分类         | 引导词             | 先行词类型  | 在从句中的成分              |
| ------------ | ------------------ | ----------- | --------------------------- |
| **关系代词** | who / whom / whose | 人          | 主语 / 宾语 / 定语          |
|              | which / whose      | 物          | 主语 / 宾语 / 定语          |
|              | that               | 人或物      | 主语 / 宾语                 |
|              | as                 | 人或物/整句 | 主语 / 宾语 / 表语          |
| **关系副词** | when               | 时间名词    | 时间状语 (= in/at/on which) |
|              | where              | 地点名词    | 地点状语 (= in/at which)    |
|              | why                | reason      | 原因状语 (= for which)      |

- **⚠️ 核心考点**：判断用关系代词还是关系副词，取决于**从句缺什么成分**。
    - 从句缺主/宾/表 → 用关系代词 (which/that/who)
    - 从句不缺主宾表，只缺状语 → 用关系副词 (when/where/why)

### 3. 状语从句引导词

**功能**：引导状语从句修饰主句的动词、形容词或整个句子，表示逻辑关系。**不在从句中充当成分**。

| 逻辑关系 | 常见引导词                                                   |
| -------- | ------------------------------------------------------------ |
| **时间** | when, while, as, before, after, until/till, since, once, as soon as, no sooner...than |
| **原因** | because, since, as, now that, seeing that                    |
| **条件** | if, unless, provided/providing that, as long as, in case     |
| **让步** | although/though, even if/even though, while, as (倒装), no matter wh-/wh-ever |
| **目的** | so that, in order that, lest, for fear that                  |
| **结果** | so...that, such...that, so that                              |
| **比较** | as...as, not so/as...as, than, the more...the more           |
| **方式** | as, as if / as though                                        |

### 💡 易混淆引导词辨析速查

同一个词可能出现在不同从句中，需根据**结构**判断：

- **that**
    - 名词性从句：纯连词，无成分 (*I know that he is right.*)
    - 定语从句：关系代词，作主/宾语 (*The book that I read...*)
    - 状语从句：搭配使用 (*so...that / such...that*)
- **when / where / why / how**
    - 名词性从句：连接副词，从句是主/宾/表语 (*I don't know where he lives.*)
    - 定语从句：关系副词，前面必须有对应的先行词 (*This is the place where he lives.*)
- **what**
    - ✅ 只能引导**名词性从句** (= the thing that)
    - ❌ **绝不能**引导定语从句

> **📌 总结口诀**：
> 名从看缺啥（缺成分选wh-，不缺选that/whether）；
> 定从看先行（人/物/时/地/因）+ 从句缺啥；
> 状从看逻辑（时间/原因/条件/让步等），不充成分只连意。

## 引导词作用是不是充当句子成分和引导

这个说法只对了一半。引导词的核心作用是“引导从句”，但“是否充当句子成分”要分情况看。

### 简单说，引导词分两类：

- 只起连接作用，不充当句子成分：主要是 `that`、`whether`、`if` 这类从属连词。它们只负责把从句和主句连起来，从句本身结构完整。比如 `I think that he is right.` 里的 that，就是纯连接，没有实际含义。`whether`、`if` 虽然表“是否”，但在从句里同样不做成分。
- 既引导从句，又充当句子成分：主要是连接代词（`who`、`what`、`which` 等）和连接副词（`when`、`where`、`why`、`how` 等）。它们本身有词义，还要在从句里当主语、宾语、状语等。比如 `I don't know what he wants.` 里的 what，既是引导词，又是 wants 的宾语。

### 不同从句里，引导词的成分情况不一样

1. 名词性从句（主语、宾语、表语、同位语从句）：`that` 不做成分、可省略（宾语从句中）；`whether/if` 不做成分、不可省略；`what/who/which` 等做主语、宾语、定语或表语；`when/where/why/how` 做状语。
2. 定语从句：关系代词（`who/which/that/whose` 等）代替先行词在从句中做主语、宾语、定语；关系副词（`when/where/why`）做状语。
3. 状语从句：引导词（如 `because`、`when`、`if` 等）在从句中不做成分，只表示逻辑关系。

### ⚠️ 一个容易混淆的点

`that` 在定语从句里是要做成分的（作主语或宾语），但在名词性从句里不做成分。比如：

> The book that I bought yesterday is interesting. （that 在定语从句中作 bought 的宾语）
> I know that he is a teacher. （that 在宾语从句中只起连接作用，不做成分）

所以更准确的说法是：引导词都起引导作用，但只有部分引导词（连接代词、连接副词、关系词）同时充当句子成分，纯连词（that/whether/if）则不充当。

引导词的用法确实容易混淆，要不要再看看关系代词和连接代词有什么区别?或者定语从句中 that 做主语的例子?

## ==哪些词可以做从句引导词==

在英语语法中，能够引导从句的词统称为**从属连词**或**关系词**。根据从句的功能不同（名词性、定语、状语），引导词的选择也有严格区分。以下是完整的分类梳理：

### 1. 名词性从句引导词

> **包括**：主语从句、宾语从句、表语从句、同位语从句

这类引导词分为三类，选择依据是**从句内部是否缺少成分**以及**缺什么成分**。

| 类别         | 引导词             | 功能与含义             | 备注                                            |
| ------------ | ------------------ | ---------------------- | ----------------------------------------------- |
| **纯连词**   | that               | 无实义，不充当成分     | 宾语从句中常可省略；主语/同位语从句不可省       |
|              | whether / if       | “是否”，不充当成分     | if 不能引导主语/表语/同位语从句及介词后宾语从句 |
| **连接代词** | who / whom / whose | 指人，作主/宾/定语     | whom 作宾语，口语中可用 who 替代                |
|              | what / whatever    | 指物/事，作主/宾/表/定 | **what = the thing(s) that**，自带先行词        |
|              | which / whichever  | “哪一个”，作主/宾/定   | 有明确选择范围时用 which                        |
| **连接副词** | when / whenever    | 时间，作时间状语       | 从句不缺主宾表时才用                            |
|              | where / wherever   | 地点，作地点状语       | 同上                                            |
|              | why                | 原因，作原因状语       | 仅用于 reason 后的表语/同位语从句               |
|              | how / however      | 方式/程度，作状语      | 注意 how 不能与 that 连用                       |

#### ⚠️ 核心辨析：that vs. what

- **that**：从句**完整**，只起连接作用。（I know *that he is right*.）
- **what**：从句**缺主/宾/表**，what 本身充当该成分。（I know *what he said*. = the thing that he said）

### 2. 定语从句引导词（关系词）

> **修饰前面的名词（先行词）**，引导词必须在从句中**充当成分**

| 先行词 | 关系代词（作主/宾/定）    | 关系副词（作状语）                      |
| ------ | ------------------------- | --------------------------------------- |
| 人     | who / whom / whose / that | when (时间) / where (地点) / why (原因) |
| 物     | which / whose / that / as | when / where / why                      |
| 人+物  | whose / that              | —                                       |

#### 🔑 只能用 that 的情况

- 先行词被序数词、最高级、the only/the very/the same 修饰
- 先行词是不定代词（all, everything, nothing, anything 等）
- 先行词既有人又有物
- 主句以 who/which 开头（避免重复）

#### 🔑 不能用 that 的情况

- **非限制性定语从句**（逗号后面）→ 用 which / who / whom / whose / as
- **介词后面** → 用 which / whom（不能用 that/who）

#### ⚠️ 关系代词 vs. 关系副词的选择

看从句**缺什么**：

- 缺主/宾/定 → 用**关系代词**（The book *which* I bought...）
- 缺状语 → 用**关系副词**（The city *where* I live... = in which）

### 3. 状语从句引导词（从属连词）

**修饰整个主句**，表示时间、原因、条件等逻辑关系，引导词**不在从句中充当成分**

| 逻辑关系 | 常用引导词                                                   |
| -------- | ------------------------------------------------------------ |
| 时间     | when, while, as, before, after, until/till, since, once, as soon as, no sooner...than, hardly...when |
| 原因     | because, since, as, now that, seeing that                    |
| 条件     | if, unless, provided/providing that, as long as, in case, suppose/supposing |
| 让步     | although/though, even though/if, while, as（倒装）, no matter + wh-, wh- + ever |
| 目的     | so that, in order that, lest, for fear that                  |
| 结果     | so...that, such...that, so that                              |
| 比较     | than, as...as, not so/as...as, the more...the more           |
| 方式     | as, as if / as though                                        |

### 三大从句引导词速查对比

| 特征                   | 名词性从句              | 定语从句             | 状语从句     |
| ---------------------- | ----------------------- | -------------------- | ------------ |
| **从句功能**           | 相当于名词              | 相当于形容词         | 相当于副词   |
| **引导词是否充当成分** | that 不充当；wh-词充当  | **一定充当**         | **不充当**   |
| **能否省略引导词**     | 仅宾语从句的 that 可省  | 作宾语的关系代词可省 | 一般不可省   |
| **典型标志**           | 位于主/宾/表/同位语位置 | 紧跟先行词           | 表示逻辑关系 |

### 实战判断流程

遇到一个空需要填引导词时，按以下顺序判断：

1. **判断从句类型**：看从句在整个句子中充当什么成分？
2. **分析从句内部**：从句是否完整？缺什么成分？
3. **匹配引导词**：
    - 名词性从句：完整选 that/whether；缺主宾选 what/who/which；缺状语选 when/where/how/why
    - 定语从句：看先行词 + 从句缺什么 → 对应关系代词或关系副词
    - 状语从句：看前后逻辑关系 → 对应从属连词

## 引导词

### what

- 只能引导**名词性从句** (= the thing that)
- **绝不能**引导定语从句

### that

- 名词性从句：纯连词，无成分 (*I know that he is right.*)
- 定语从句：关系代词，作主/宾语 (*The book that I read...*)
- 状语从句：搭配使用 (*so...that / such...that*)

### when / where / why / how

- 名词性从句：连接副词，从句是主/宾/表语 (*I don't know where he lives.*)
- 定语从句：关系副词，前面必须有对应的先行词 (*This is the place where he lives.*)

## 怎么确定==从句的引导词用哪一个==

确定从句引导词（关系词/连词）不能靠“语感”或死记硬背，而需要遵循一套严密的**逻辑判断流程**。核心在于先定性“从句类型”，再根据“句法功能”或“逻辑关系”锁定具体词汇。

以下是三大从句引导词的精准选择路径：

### 1. 定语从句：看“先行词”+“从句缺什么”

定语从句的引导词选择是语法性最强的，必须同时满足两个条件：**指代对象匹配** + **从句成分完整度**。

#### 第一步：判断先行词属性

- **人** → who / whom / whose / that
- **物** → which / whose / that
- **时间** → when / that
- **地点** → where / that
- **原因** → why / that

#### 第二步：分析从句内部结构（最关键！）

将引导词代入从句，判断它在从句中充当什么成分：

| 从句缺失成分         | 引导词选择          | 示例与辨析                                                   |
| -------------------- | ------------------- | ------------------------------------------------------------ |
| **主语/宾语**        | who/whom/which/that | The man  **(who/that)**  I met yesterday... (met缺宾语)      |
| **定语(所属关系)**   | whose (+ n.)        | The girl **whose father** is a doctor... (father缺定语)      |
| **状语(主谓宾完整)** | when/where/why      | The city **where** I was born... (I was born主谓完整，缺地点状语) |
| **表语**             | as / that           | This is the same book **as** I bought. (as作bought的宾语且呼应same) |

⚠️ **高频易错点：when/where/why vs. which/that**

> - I'll never forget the day **when** we first met. (we first met 完整，缺时间状语)
> - I'll never forget the day **which/that** we spent together. (spent 缺宾语，day作宾语)
> - **检验方法**：把先行词代入从句，若能直接作主语/宾语用 which/that；若需加介词(in/on/at/during)才通顺，则用 when/where/why。

#### 特殊规则速查

- **只能用 that**：先行词被序数词、最高级、the only/the very/all/every/no修饰；先行词既有人又有物；主句以who/which开头避免重复。
- **不能用 that**：非限制性定语从句（逗号后）；介词提前时（in which ≠ in that）。
- **as vs. which**：as 可置于句首，常与 such/same/the same 搭配，表“正如”；which 只能置于主句后，表“这一点”。

### 2. 名词性从句：看“从句是否完整”+“语义需求”

名词性从句（主/宾/表/同位语）的引导词选择不依赖先行词，而取决于**从句本身的完整性**和**你想表达的含义**。

#### 决策树

1. **从句意思完整，不缺成分？**
   - 是 → **that**（无实义，仅起连接作用，宾语从句中可省略）
   - *I believe ****that**** he is honest.* (he is honest 完整)
2. **从句缺主语/宾语/表语？**
   - 指物 → **what** (= the thing that)
   - 指人 → **who / whoever**
   - 指时间/地点/原因 → **when / where / why**
   - *I don't know ****what**** he wants.* (wants缺宾语)
3. **从句缺定语（修饰名词）？**
   - **whose / which / what** (+ n.)
   - *Tell me ****whose book**** this is.*
4. **表示“是否”？**
   - 句首主语从句/介词后 → **whether**（不用if）
   - 动词宾语从句 → **whether / if** 均可
   - 与or not连用/不定式前 → **whether**

**what vs. that 终极区分**：

> - **what** = 内容本身（= the thing(s) that），在从句中**必作成分**。
> - **that** = 纯粹连接词，在从句中**不作任何成分**，仅标志从句开始。
> - 检验：去掉引导词后从句仍完整 → that；去掉后缺成分 → what。

### 3. 状语从句：看“逻辑关系”

状语从句引导词纯粹由**主句与从句之间的逻辑语义**决定，与句子结构无关。需先理解句意，再从逻辑类别中选词。

| 逻辑关系 | 常用引导词                                                   | 选词细微差别                                                 |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **时间** | when / while / as / before / after / until / since / once / as soon as | while强调“同时进行”或“对比”；as强调“伴随变化”；until强调“直到…才/为止” |
| **原因** | because / since / as / now that / seeing that                | because语气最强，回答why；since/as表已知原因；now that表“既然（新情况）” |
| **条件** | if / unless / provided that / as long as / on condition that | unless = if...not；provided that偏正式契约语境               |
| **让步** | although / though / even if / even though / while / as       | although最正式；even if强调“即使（假设）”；as引导时需倒装    |
| **目的** | so that / in order that / lest / for fear that               | lest/for fear that后接(should)+动词原形                      |
| **结果** | so...that / such...that / so that                            | so/such选择见前述规则；so that表结果时无逗号                 |
| **方式** | as / as if / as though                                       | as if后接虚拟语气表“仿佛（非事实）”                          |
| **比较** | as...as / than / not so...as                                 | 注意比较对象对等                                             |

⚠️ **易混逻辑辨析**：

- **while**：可表时间（当…时）、让步（虽然）、对比（然而），需根据上下文判断。
- **since**：可表时间（自从）、原因（既然），时间义时主句常用完成时。
- **as**：可表时间、原因、方式、让步、比较，是含义最多的连词，务必结合语境。

### 通用避坑原则

1. **先判类型，再选词**：看到空格不要急着填，先判断这是定语、名词性还是状语从句。同一单词（如that/when/where）在不同从句中功能完全不同。
2. **成分分析法是金标准**：尤其定语从句和名词性从句，必须分析从句内部缺什么成分，而非仅凭先行词或中文翻译选词。
3. **警惕“假朋友”**：中文翻译相同≠英文引导词相同。例如“……的地方”可能是where（状语从句/定语从句状语），也可能是which（定语从句宾语）。
4. **形式主语it的干扰**：It is...that...强调句中，that是固定搭配，不受先行词影响；但It is clear that...中that是主语从句引导词，需按名词性从句规则判断。

### 实操训练建议

- **错题归因**：每次选错引导词，记录错误原因（类型误判？成分分析错？逻辑理解偏差？），建立个人易错点清单。
- **反向验证**：选出引导词后，将其代入从句检验：成分是否完整？逻辑是否通顺？是否符合特殊规则？
- **语境积累**：收集真题或外刊中引导词使用的典型例句，按“易混对比”分组记忆（如when vs. which, what vs. that, while多义），比孤立背规则更有效。

## ==引导词选择==

引导词多但不乱，核心就一句话：**先看从句类型，再看从句里缺什么成分，最后匹配引导词**。 三步走下来，基本不会选错。

### 判断三步法

1. 定类型：先看空格后面是什么从句。名词性从句（主语/宾语/表语/同位语）、定语从句、状语从句，判断依据看空格位置和前面的词。
2. 析成分：把从句单独拿出来，去掉空格位置，看句子缺什么。缺主语、宾语用连接代词；缺状语用连接副词；啥都不缺就用只起连接作用的词。
3. 对选项：根据类型和成分需求，匹配对应的引导词。

### 各类从句引导词速查

| 从句类型   | 缺什么       | 用哪个                                                       |
| ---------- | ------------ | ------------------------------------------------------------ |
| 名词性从句 | 缺主/宾/表语 | 指人 who/whom，指物 what/which，所属 whose                   |
|            | 缺状语       | when（时间）、where（地点）、why（原因）、how（方式）        |
|            | 不缺成分     | that（陈述）、whether/if（是否）                             |
| 定语从句   | 缺主/宾/定语 | 指人 who/whom/that，指物 which/that，所属 whose              |
|            | 缺状语       | when（时间）、where（地点）、why（原因，先行词为reason）     |
| 状语从句   | 成分完整     | 看逻辑关系：时间用when/while，原因用because/since，条件用if/unless，让步用though/although |

⚠️ 几个容易踩的坑

- that和what：that只连接不作成分，what在从句里要作主/宾/表语。比如“____ he said is true”缺宾语，用what；“____ he is a student is true”成分完整，用that。
- where和which：定语从句中，先行词是地点但从句缺状语用where，缺宾语用which/that。比如“the city ____ I was born”缺状语用where；“the city ____ I visited”缺宾语用which/that。
- whether和if：主语从句、表语从句、同位语从句、介词后面只能用whether；和or not连用也用whether。
- that省略：只有宾语从句中的that可以省略，其他从句都不行。

> 判断引导词就像给衣服找扣子——先看清是衬衫还是外套（定从句类型），再看扣眼大小位置（看句子成分），最后找对应的扣子（选引导词）。

实际做题时按三步法走一遍，练几道真题找找感觉，规律很快就能掌握。

掌握三步法后，可以再看看that和whether的用法区别或者which和that的用法区别

## 关系代词和连接代词

连接代词引导名词性从句（主语、宾语、表语、同位语从句），关系代词引导定语从句，核心区别在于连接代词没有先行词而关系代词有先行词。

### 定义与代词列表

1. 连接代词：指疑问代词在引导从句时的语法名称，用于引导名词性从句，在从句中充当主语、宾语等成分。
   - 主要包括：who、whom、whose、what、which、that。
   - 带-ever 后缀的：whoever、whomever、whatever、whichever。
   - 注意：what 只能作连接代词，不能作关系代词。
2. 关系代词：引导定语从句并在从句中充当句子成分的代词，代表主句中的先行词。
   - 主要包括：who、whom、whose、which、that。
   - 根据剑桥词典，that 可作为关系代词引导限定性定语从句，比 who 或 which 更口语化。
   - 大英百科全书确认关系代词包括 who、whom、whose、that、which。

### 核心区别

1. 引导的从句类型不同
   - 连接代词：引导名词性从句（主语从句、宾语从句、表语从句、同位语从句）。
   - 关系代词：引导定语从句。
2. 是否有先行词
   - 连接代词：没有先行词，没有替代作用。
   - 关系代词：代替主句中作为先行词的名词或代词。
3. 代词范围不同
   - 连接代词比关系代词多一个 what。
   - 部分代词形式重合：who、whom、which、whose 既可用作关系代词，也可用作连接代词。

### 用法举例

1. 连接代词用法
   - 主语从句：Who is to be the head is not yet decided.（谁做领导还没有决定）。
   - 宾语从句：Jack may marry whom he loves.（杰克爱谁，就可以和谁结婚）。
   - 表语从句：This is what she wrote.（这是她写的论文）。
   - 宾语从句：Show me what you had.（给我看看你有什么）。
2. 关系代词用法
   - 定语从句：The boy who spoke is my friend.（刚才讲话的男孩是我的朋友）。
   - 定语从句：I have just met the man whom I saw yesterday.（我刚遇到昨天见到过的那个男人）。
   - 定语从句：He is the man whose car was stolen.（他就是汽车被窃的人）。
   - 定语从句：This is the paper that she wrote.（这是她写的论文）。
3. 快速判断方法
   - 看从句类型：名词性从句用连接代词，定语从句用关系代词。
   - 看有无先行词：有先行词是关系代词，无先行词是连接代词。
   - 看是否有 what：出现 what 一定是连接代词。

# 先行词

**先行词**是定语从句中被==关系词==（who, which, that, where 等）==所指代和修饰的名词、代词或短语==。它是整个定语从句存在的逻辑基础，决定了关系词的选择以及从句谓语动词的单复数。

理解先行词不能仅停留在“被修饰的词”这一表层定义，更需要掌握其在复杂语境下的判定规则。以下是先行词的核心知识体系：

### 1. 先行词的常见形态

| 形态分类               | 示例                                                   | 说明                         |
| ---------------------- | ------------------------------------------------------ | ---------------------------- |
| **普通名词**           | The **book** that I bought...                          | 最典型的形式                 |
| **代词**               | **Those** who want to go... / **All** that glitters... | 不定代词、指示代词常作先行词 |
| **专有名词**           | **Beijing**, which is the capital...                   | 多为非限制性定语从句的先行词 |
| **整个句子/段落**      | He failed the exam, **which** surprised us.            | 仅由 which/as 指代，表整件事 |
| **抽象概念/时间/地点** | The **reason** why... / The **day** when...            | 决定使用关系副词             |

### 2. ⚠️ 核心难点：先行词的“隐形”与“分离”

在考试和长难句中，先行词往往不那么直观，需注意以下三种特殊情况：

#### 先行词与关系词被分隔

定语从句有时会被插入语、谓语动词或其他成分隔开，导致先行词不紧邻关系词。

- A new teacher will come tomorrow **who** has taught in America for years.
    - *解析*：先行词是 *teacher*，而非 *tomorrow*。从句被谓语 *will come tomorrow* 分隔，以避免头重脚轻。

#### 先行词为“隐含”的整体概念

当关系词指代的不是某个具体单词，而是前面整个分句表达的含义时，先行词是“隐性”的。

- She married him young, **which** was a mistake.
    - *解析*：*which* 的先行词不是 *him* 或 *young*，而是“她年轻时嫁给他”这整件事。

#### 双重先行词

在嵌套定语从句中，一个词可能同时充当外层从句的先行词和内层从句的关系词所指对象。

- This is the house **that** Jack built **which** is now a museum.
    - *解析*：*house* 是 *that* 的先行词；而 *which* 的先行词同样是 *house*（或整个 *the house that Jack built* 短语），形成链式修饰。

### 3. 先行词对关系词的制约规则

先行词的性质直接锁定关系词的选择范围：

| 先行词特征                             | 强制/优先使用的关系词      | 禁用/慎用的关系词 |
| -------------------------------------- | -------------------------- | ----------------- |
| 人 + 物混合                            | **that**                   | who, which        |
| 不定代词 (all, everything, nothing...) | **that**                   | which             |
| 序数词/最高级/the only/the very 修饰   | **that**                   | which, who        |
| 非限制性从句中的“物”                   | **which**                  | **that** ❌        |
| 非限制性从句中的“整句”                 | **which / as**             | that ❌            |
| 介词之后                               | **whom / which**           | that, who ❌       |
| way (方式)                             | **that / in which / 省略** | how ❌             |

### 4. 先行词与主谓一致

定语从句中谓语动词的单复数**严格取决于先行词**，而非关系词本身：

- **一般原则**：I am one of the students who **are** late. （先行词 *students* → 复数）
- **特例**：I am **the only one** of the students who **is** late. （先行词 *the only one* → 单数）
- **分数/百分数**：Two thirds of the **water** that **is** polluted... （先行词 *water* → 单数）
- **集合名词**：The **team** that **is/are** winning... （视强调整体还是个体而定）

### 实战判定口诀

> **找先行，看位置，不邻接时查逻辑；**
> **定关系，析成分，缺啥补啥是关键；**
> **主谓数，跟先行，only one 要记清。**

建议在阅读长难句时，养成==用括号标出先行词、用箭头连接关系词==的习惯，通过可视化训练强化对先行词敏感度的培养。

# 定语从句

## 定语从句

定语从句是英语语法中最核心的复合句类型之一，它相当于一个**形容词**，用来修饰名词、代词或整个句子。掌握定语从句的关键在于理清“先行词”、“关系词”与“从句内部成分”三者之间的逻辑关系。

以下是定语从句的完整知识体系：

### 1. 核心结构公式

**先行词 + 关系词 + 定语从句**

- **先行词**：被修饰的名词/代词（如 *the book*）。
- **关系词**：引导从句并指代先行词的词（如 *which, that, who*）。
- **双重功能**：关系词既起**连接**作用，又在从句中**充当成分**（主语、宾语、定语或状语）。

### 2. 关系词选择矩阵

选择关系词需同时考虑两个维度：**先行词的类型** + **从句缺失的成分**。

| 从句缺失成分 | 先行词为人              | 先行词为物       | 备注                         |
| ------------ | ----------------------- | ---------------- | ---------------------------- |
| **主语**     | who / that              | which / that     | that 在限制性从句中通用      |
| **宾语**     | whom / who / that       | which / that     | ==作宾语时关系词常可省略==   |
| **定语**     | whose                   | whose / of which | whose + n. = of which the n. |
| **时间状语** | when (= in/at/on which) | when             | 先行词必须是时间名词         |
| **地点状语** | where (= in/at which)   | where            | 先行词必须是地点名词         |
| **原因状语** | why (= for which)       | —                | 先行词通常仅为 reason        |

#### ⚠️ 关键判断步骤

不要看到 `time/place/reason` 就条件反射选 `when/where/why`， 必须先分析从句是否缺主宾表：

- This is the factory **where** I worked. (worked 不及物，不缺宾语 → 用 where)
- This is the factory **that/which** I visited. (visited 及物，缺宾语 → 用 that/which)

### 3. 限制性 vs. 非限制性定语从句

| 特征     | 限制性定语从句            | 非限制性定语从句               |
| -------- | ------------------------- | ------------------------------ |
| **形式** | 无逗号隔开                | 有逗号隔开                     |
| **意义** | 必不可少，限定先行词范围  | 补充说明，删去不影响主句完整性 |
| **that** | 可用                      | **绝不可用**                   |
| **as**   | 仅用于 such/the same...as | 可指代整句，位置灵活           |
| **翻译** | “...的”                   | “这...”，“他/她/它...”         |

- **非限特例**：`as` 与 `which` 都可指代整句，但 `as` 含“正如”之意且可置于句首；`which` 仅表事实陈述，只能置于句中或句末。

### 4. 必须用 that 的特殊情况

当先行词出现以下情形时，关系词**只能用 that**，不能用 which/who：

1. 先行词是不定代词：all, everything, nothing, anything, little, much 等
2. 先行词被序数词或最高级修饰：the first, the best, the most important
3. 先行词被 the only, the very, the last, just the 修饰
4. 先行词既有人又有物：the teacher and his students
5. 先行词被 all, every, no, any 修饰

### 5. 高频易错点警示

- **介词+关系词**：介词后只能用 **whom**（人）或 **which**（物），**绝不能用 that/who**。
    - The house **in which** I live...
    - The house ~~in that~~ I live...
- **way 作先行词**：关系词可用 **that / in which / 省略**，但不用 how。
    - The way (that/in which) he solved it...
- **one of + 复数名词**：从句谓语动词用**复数**。
    - He is one of the students who **are** late.
- **the only one of + 复数名词**：从句谓语动词用**单数**。
    - He is the only one of the students who **is** late.

### 学习建议

定语从句的本质是  ==**还原法**== ：将关系词还原到从句中，看它在从句里做什么成分。养成这个思维习惯，比死记硬背规则更有效。建议结合长难句分析进行实战训练，重点关注关系词在从句中的语法角色判定。

非限制性定语从句是对先行词或整个主句进行补充说明的从句，去掉后主句意思仍然完整。其核心特征与用法如下：

- 形式特征：与主句之间必须用逗号隔开，口语中有停顿 。
- 引导词限制：可用 who, which, as 等，不能用 that 引导，且关系词不可省略。
- 修饰对象：既可修饰单个名词，也可修饰整个主句（常用 which 或 as）。
- 与限制性从句区别：限制性从句起限定作用（无逗号、可用 that、可省略），非限制性从句仅起补充作用（有逗号、无 that、不可省略）。
- 典型例句：*The sun heats the earth, which makes it possible for plants to grow.*（which 指代整个主句）。


根据 Purdue OWL 等权威语法指南，此类从句提供非essential信息，标点与引导词选择是关键识别标志 。

## 作宾语的关系词常可省略

对，定语从句中作宾语的关系代词确实常可省略，但有几个限制条件需要留意。

### 可省略的情况

1. 作动词宾语：关系代词在从句中直接作谓语动词的宾语，如 `The book (that/which) I read is interesting.`
2. 作介词宾语且介词在句尾：介词放在从句末尾时，关系代词可省略，如 `This is the place (which) we talked about.`

### 不可省略的情况

1. 作主语：关系代词作主语时不能省，否则从句结构不完整，如 `The man who called you...` 中 `who` 不能省。
2. 介词提前：介词被提到关系代词前面，构成“介词+关系代词”结构时，关系词必须保留，且指人只能用 `whom`，指物只能用 `which`。
3. 非限制性定语从句：带逗号的非限制性定语从句中，关系词一律不能省略。

> 简单记：关系词作宾语时，99%都能省，唯一的例外就是介词被提前时。

### 补充两点

- 作表语也可省：关系代词 `that` 在从句中作表语时也能省略，如 `She is not the girl (that) she used to be.`
- 先行词为 way/time/reason 等：作状语时，`that/in which/when/why` 等也常可省略，如 `The way (that) you look at the problem is wrong.`

## in which

in which 是“介词 + which”结构，用于==引导定语从句==，常见意思为“在其中、在...里”，可以理解为 where（表地点/场合）或 when（表时间）的正式替代表达。

---

### 核心用法

1. 表地点/场合：相当于 where
   - The room in which we met is small. → The room where we met is small.
   - 我们见面的那个房间很小。

2. 表时间：相当于 when
   - I remember the year in which he was born. → I remember the year when he was born.
   - 我记得他出生的那一年。

3. 与从句中动词搭配：如果从句里有“动词 + in”的固定搭配，介词要保留 in
   - This is the book in which I'm interested. (= be interested in)
   - 这是让我感兴趣的那本书。

### ⚠️ 易混淆点

in which ≠ which：which 在从句中作主语或宾语，而 in which 作状语。

> 对比：This is the house which I bought.（which 作 bought 的宾语）  
> This is the house in which I lived.（从句不缺宾语，缺地点状语）

### 与其他介词 + which 的区别

| 结构       | 常见搭配对象     | 相当于       |
| ---------- | ---------------- | ------------ |
| in which   | 地点、范围、时间 | where / when |
| on which   | 具体日期、表面   | when / where |
| at which   | 具体地点、场合   | where / when |
| by which   | 方式、手段       | how          |
| with which | 工具、伴随       | with + 名词  |
| for which  | 原因、目的       | why          |
| of which   | 所属关系         | whose + 名词 |

介词的选择取决于先行词类型，以及从句中动词、形容词与介词的固定搭配。

### 使用建议

in which 语气更正式，多用于书面语或正式文章；口语中直接用 where / when 更自然。 

==做题时判断口诀==：从句缺主宾用 which，缺状语用 where / when（或介词 + which），别只盯着先行词是人还是物。

in which 的用法挺多的，要不要继续看看in which 和 which 从句结构有何不同?或者in which 为什么比 where 正式?

# 状语从句

## 状语从句

状语从句是复合句中充当**状语**成分的从句，用来修饰主句的谓语动词、形容词、副词或整个句子，说明动作发生的时间、地点、原因、条件、让步、目的、结果、方式及比较等背景信息。

与定语从句不同，状语从句**不修饰名词**，而是修饰“动作”或“状态”。掌握状语从句的核心在于：**识别逻辑关系 + 选对连词 + 注意特殊句式**。

### 1. 九大状语从句分类速查表

| 类别     | 核心连词                                                     | 关键注意点                                                   |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **时间** | when, while, as, before, after, until/till, since, once, as soon as | ⚠️ **主将从现**：主句将来时，从句用一般现在时表将来           |
| **地点** | where, wherever                                              | where 还可引导定语从句，需根据是否修饰名词区分               |
| **原因** | because, since, as, now that, seeing that                    | because 语气最强；since/as 表已知原因；now that 表“既然”     |
| **条件** | if, unless, provided/providing that, on condition that, as long as | unless = if...not；条件句同样遵循**主将从现**                |
| **让步** | although/though, even if/even though, while, as, no matter wh-, wh- + ever | ⚠️ although/though **不可与 but 连用**；as 引导让步从句需**倒装** |
| **目的** | so that, in order that, lest, for fear that                  | lest / for fear that 后接 **(should) + 动词原形**            |
| **结果** | so...that, such...that, so that                              | so/such 的选择取决于中心词是形容词/副词还是名词              |
| **方式** | as, as if / as though                                        | as if 后可用虚拟语气（与事实相反）或陈述语气（可能为真）     |
| **比较** | as...as, not as/so...as, than                                | 比较对象需对等，避免歧义                                     |

### 2. ⚠️ 三大高频易错点

#### “主将从现”原则

在**时间状语从句**和**条件状语从句**中，即使表达将来的动作，从句也必须用**一般现在时**（或现在完成时），只有主句才用将来时。

- I **will call** you as soon as he **arrives**.
- ~~I will call you as soon as he will arrive.~~
- **例外**：若 when/if 引导的是宾语从句而非状语从句，则正常用将来时：*I don't know when he will come.*

#### 让步从句的倒装结构

当 **as / though** 引导让步状语从句时，必须将==表语、状语或动词原形==提前至句首：

- **Child as he is**, he knows a lot. （名词提前，且省略冠词）
  - as 表“虽然”时，需将表语（Child）前置至句首
  - 他虽然是个孩子，却懂得很多

- **Hard as he tried**, he failed. （形容词/副词提前）
- **Try as he might**, he couldn't succeed. （动词原形提前）
  - 尽管他可能很努力, 最终还是没能成功

- ~~As he is a child, he knows a lot.~~ （不倒装则错误）

**注**：although 引导让步从句时**永不倒装**。

#### so...that vs. such...that 的选择

| 结构                                  | 用法                  | 示例                             |
| ------------------------------------- | --------------------- | -------------------------------- |
| so + adj./adv. + that                 | 中心词是形容词或副词  | so **beautiful** that...         |
| such + (a/an) + (adj.) + n. + that    | 中心词是名词          | such a **beautiful day** that... |
| so + many/much/few/little + n. + that | 数量词修饰名词        | so **many people** that...       |
| such + little + n. + that             | little 表“小”而非“少” | such **little birds** that...    |

**记忆口诀**：**名**词归 such，**形副**归 so；多少用 so，大小用 such。

### 3. ==状语从句 vs. 定语从句辨析==

这是考试中最容易混淆的点，尤其涉及 **when / where / why** 时：

| 判断维度               | 状语从句                                            | 定语从句                                            |
| ---------------------- | --------------------------------------------------- | --------------------------------------------------- |
| **功能**               | 修饰动词/整句，表时间/地点/原因                     | 修饰名词，限定先行词                                |
| **前面有无名词**       | 通常无（或名词不是被修饰对象）                      | 必须有先行词                                        |
| **能否替换为介词短语** | 通常可以（如 at that time）                         | 不能                                                |
| **例句对比**           | I went to bed **when I finished work**. (修饰 went) | I remember the day **when I graduated**. (修饰 day) |

### 学习建议

1. **以逻辑关系为纲**：不要孤立背连词，而要按“因果、转折、条件”等逻辑归类记忆。
2. **重视语境翻译**：同一个连词在不同语境下可能属于不同类别（如 while 可表时间、让步、对比）。
3. **造句训练**：针对每个易错点（如倒装、主将从现）各造3-5个句子，比单纯阅读规则更有效。
4. **长难句拆解**：在阅读中遇到复杂句，先划出状语从句的起止位置，再分析其与主句的逻辑关系，逐步培养语感。

# 从句倒装

## 从句倒装

英语中==as/though 引导的让步状语从句==和==省略 if 的虚拟条件从句==常用倒装语序。

- as/though 让步状语从句：把表语、状语或动词原形提前到从句句首，如“Child as he is, he knows a lot”。
- 省略 if 的虚拟条件从句：把 had/should/were 提到主语前，如“Had I known, I would have told you”。


常见误区：Only 或 Not until 后接从句时，是主句倒装，从句本身不倒装。

## 哪些从句需要倒装

英语里需要倒装的从句主要有两类：让步状语从句和虚拟条件句。另外在部分固定结构中，从句本身不倒装，而是主句倒装，这点容易搞混，也一并说清楚。

### 需要倒装的从句

1. 让步状语从句（as / though 引导）：把表语、状语或动词原形提到从句开头，构成部分倒装。
   - 例：Child as he is, he knows a lot.（虽然他是个孩子，他懂很多。）
   - 例：Hard as he tried, he failed the exam.（尽管他很努力，还是没及格。）

2. 虚拟条件句（省略 if 时）：从句中有 were、had、should 时，省略 if 后把它们提到主语前。
   - 例：Had you come earlier, you would have met her.（如果你早点来，就能见到她了。）
   - 例：Were I you, I would accept the offer.（如果我是你，我会接受这个提议。）

### 从句不倒装、主句倒装的情况

这类结构常被误认为“从句倒装”，实际规则是“前倒后不倒”——从句保持正常语序，主句用部分倒装。

1. not only… but also…：not only 引导的分句倒装，but also 后的分句不倒装。
   - 例：Not only did he refuse the gift, but he also criticized the sender.

2. hardly/scarcely… when… 和 no sooner… than…：hardly、no sooner 所在的分句倒装，后面的分句不倒装。
   - 例：Hardly had he arrived when it began to rain.
   - 例：No sooner had she left than the phone rang.

3. only + 状语从句：only 引导的状语从句本身不倒装，主句倒装。
   - 例：Only when he is seriously ill does he stay in bed.

4. not until…：not until 引导的从句不倒装，主句倒装。
   - 例：Not until the child fell asleep did the mother leave the room.

> 需要区分的是，以 whether、whatever、no matter 等引导的让步从句，以及普通的时间、原因、条件从句，都不需要倒装，保持正常语序即可。

倒装规则里有些细节容易混淆，要不要看看as if 引导的让步从句需要倒装吗?或者虚拟条件句中 should 的用法有什么不同?

# ==从句简化==

从句的简化（Clause Reduction）是英语从“语法正确”迈向“地道精炼”的关键一步。其核心原则只有一条：**当从句主语与主句主语一致（或为泛指/形式主语）时，可省略主语和be动词，将谓语动词转化为非谓语形式（分词/不定式）或介词短语。**

简化不是随意删减，而是有严格条件的句式压缩。以下是三大类从句的简化规则、操作步骤及避坑指南。

### 1. 状语从句的简化（最高频）

状语从句简化后通常变为**分词短语**或**介词短语**，保留原连词（except for *because*）。

#### 核心公式

**连词 + 主语 + be + V-ing/V-ed/adj./prep. phrase → 连词 + V-ing/V-ed/adj./prep. phrase**

| 原从句类型    | 简化规则           | 原句 → 简化句                                                |
| ------------- | ------------------ | ------------------------------------------------------------ |
| **主动/进行** | 保留 V-ing         | While **he was walking** down the street, he met an old friend.→ While **walking** down the street, he met an old friend. |
| **被动/完成** | 保留 V-ed          | After **the project was completed**, we celebrated.→ After **completed**, we celebrated. *(更常见：After completing / Upon completion)* |
| **系表结构**  | 保留 adj./n./prep. | Although **she was tired**, she kept working.→ Although **tired**, she kept working. |
| **There be**  | 保留 There being   | Because **there was no bus**, we walked home.→ **There being no bus**, we walked home. |

⚠️ **关键限制**：

- **主语必须一致**：~~While walking down the street, a car hit him.~~ （错误！walking 的逻辑主语变成了 car）
- **Because 不能直接简化为 V-ing**：需改为 **Because of + 名词** 或 **Due to / Owing to**。
    - ✅ Because of the rain, we stayed home.
    - ❌ ~~Being raining, we stayed home.~~
- **时间/条件连词可保留也可省略**：When/While/If/Although 简化后常保留以明确逻辑；before/after 简化后常变为 Before/After + V-ing（此时词性转为介词）。

### 2. 定语从句的简化

定语从句简化后变为**前置形容词**、**后置分词短语**或**介词短语**，关系词一律删除。

| 原结构                   | 简化方式                   | 示例                                                         |
| ------------------------ | -------------------------- | ------------------------------------------------------------ |
| 关系词 + be + V-ing      | V-ing 后置                 | The man **who is standing** there → The man **standing** there |
| 关系词 + be + V-ed       | V-ed 后置                  | The book **which was written** by Lu Xun → The book **written** by Lu Xun |
| 关系词 + be + adj./prep. | adj./prep. 后置或前置      | The girl **who is beautiful** → The **beautiful** girl / The girl **beautiful** in her dress |
| 关系词 + V (主动)        | V-ing 替换                 | The train **that arrives** at 8 → The train **arriving** at 8 |
| 关系词 + have/has + V-ed | having V-ed (强调先于主句) | The students **who have finished** the exam → The students **having finished** the exam |

**特别注意**：

- 若定语从句中的动词是**短暂性动作**且与主句动作同时发生，简化为 V-ing 可能产生歧义，建议保留从句。
- 非限制性定语从句（有逗号）**一般不简化**，因其补充说明功能在简化后易丢失。

### 3. 名词性从句的简化

名词性从句（主语/宾语/表语/同位语从句）简化空间最小，仅在特定结构中可行。

| 原结构                                | 简化方式                               | 示例                                                         |
| ------------------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| wh- + to do                           | 疑问词 + 不定式                        | I don't know **what I should do**. → I don't know **what to do**. |
| that + S + be + adj./n.               | It + be + adj./n. + for/of sb. + to do | **That he refused** surprised us. → **His refusal** surprised us. (名词化) |
| whether/if + S + can/could/should + V | whether + to do                        | She wondered **whether she could go**. → She wondered **whether to go**. |

⚠️ **不可简化的情况**：

- that 引导的主语/宾语从句（除固定句型 It is...that...外）
- 从句主语与主句主语不一致时
- 从句含独立的情态意义或时态对比时

### 四大避坑清单

1. **悬垂分词**：简化后分词的逻辑主语 ≠ 主句主语 → **绝对错误**。修改方法：补回从句主语，或调整主句主语。
2. **时态/语态错位**：简化后的分词必须准确反映原从句的时态和语态。完成时用 having done/having been done；被动用 done/being done。
3. **逻辑连词丢失**：状语从句简化时，若省略连词导致逻辑模糊（尤其是让步、条件），**务必保留连词**。
4. **过度简化**：并非所有符合条件的从句都该简化。当简化后造成歧义、节奏失衡或信息损失时，**保留完整从句才是上选**。

### 实操建议

- **阅读反向训练**：遇到分词短语、介词短语作状语/定语时，尝试还原为完整从句，验证理解是否正确。
- **写作正向应用**：初稿写完整从句确保语法正确，二稿再按规则简化以提升文风紧凑度。
- **优先掌握状语从句简化**：这是考试和学术写作中收益最高的部分，定语从句次之，名词性从句了解即可。
