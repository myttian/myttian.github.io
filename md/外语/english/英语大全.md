# 英语核心内容除了从句、时态、非谓语动词,还有什么

你提到的从句、时态、非谓语动词确实是英语语法的“三座大山”，但它们只是骨架的一部分。要真正搭建起完整的英语能力体系，还需要补齐下面这几大板块。我按**重要程度**帮你梳理成一张地图：

## 一、词法基础（地基，最容易被忽视）

很多人语法题错、写作卡壳，问题往往不在从句，而在这些“小词”上：

| 模块             | 核心考点                                                     |
| ---------------- | ------------------------------------------------------------ |
| **名词**         | 可数/不可数、单复数变化、所有格（'s 与 of 结构）、抽象名词具体化 |
| **冠词**         | a/an/the 的本质区别、零冠词的场合、固定搭配中的冠词          |
| **代词**         | 人称/物主/反身/相互代词、it 的指代、不定代词（some/any/every/no 系列） |
| **形容词与副词** | 比较级最高级、-ed/-ing 形容词区别、修饰位置、as...as 结构    |
| **介词**         | 时间/地点/方式介词、介词+动名词、动词与介词的固定搭配        |
| **连词**         | 并列连词（and/but/or/so）、从属连词的逻辑关系                |

> 💡 **提醒：** 介词和搭配是中式英语的重灾区。比如“在周末”是 on the weekend 而非 in the weekend，这类细节靠背规则不如靠积累语块。

## 二、句法结构（句子的“骨架”）

- **五大基本句型：** 主谓 / 主系表 / 主谓宾 / 主谓双宾 / 主谓宾补。这是所有复杂句的起点，分析长难句时第一步就是找主干。
- **主谓一致：** 就近原则、就远原则、集合名词、不定代词作主语、并列主语等，考试高频。
- 特殊句式：
  - **There be 句型**（存在句）
  - **It 作形式主语/形式宾语**（It is important to... / I find it hard to...）
  - **倒装句**（完全倒装、部分倒装，如否定词开头、only 状语开头）
  - **强调句**（It is... that/who...）
  - **省略句**（并列句中的省略、状语从句省略）
  - **平行结构**（and/or 前后成分必须对称，写作评分点）

## 三、语态与语气

- **被动语态：** 各时态的被动形式、get-passive、以及“系表结构”与“被动语态”的区分（The door is closed. 是状态还是动作？）。
- **情态动词：** can/could、may/might、must、should、will/would、need、dare。重点不是“能/会”，而是**表推测**（must be 一定、can't be 不可能、may be 也许）和**表虚拟/建议**。
- **虚拟语气：** 虽然常出现在从句里，但它本身是一套独立的语气系统（与现在/过去/将来事实相反），需要单独成块掌握。
- **句子功能类型：** 陈述句、疑问句（一般/特殊/选择/**反意疑问句**）、祈使句、感叹句。反意疑问句是高频易错点。

## 四、词汇层面（比语法更决定表达质量）

语法只保证“句子正确”，词汇才决定“表达地道”：

- **构词法：** 前缀（un-, dis-, re-, mis-）、后缀（-tion, -ment, -able, -ly）、合成词、词性转换。掌握后词汇量能成倍增长。
- **动词短语（Phrasal Verbs）：** give up / give in / give out / give away 意义完全不同，是口语和阅读的核心。
- **固定搭配与词块（Collocations）：** make a decision（不是 do a decision）、heavy rain（不是 big rain）。
- **近义词辨析：** 比如 say/tell/speak/talk、affect/influence/effect。
- **一词多义与熟词生义：** 阅读理解的常见陷阱，如 address（地址/解决/演讲）、book（书/预订）。

## 五、语音与书写（输出端的“隐形分”）

- **语音：** 音标、单词重音、句子重音、**连读弱读**（你前面问过的）、语调升降。这直接决定听力和口语水平。
- **书写规范：** 大小写规则、标点符号（英语没有顿号、书名号用法不同）、缩写形式。
- **段落与篇章：** 主题句 + 支撑句 + 结论句的结构，以及衔接手段（however, therefore, in addition, for instance）。写作拿高分靠的是这个，不是堆砌从句。

## 六、优先级建议

如果你的目标是**应试**，建议顺序：

> 词法基础 → 五大句型与主谓一致 → 时态语态 → 从句 → 非谓语 → 情态与虚拟 → 特殊句式

如果目标是**实际使用（口语/写作）**，建议顺序：

> 高频词汇与搭配 → 基本句型 → 常用时态 → 语音语调 → 篇章逻辑 → 复杂句式（从句、非谓语作为“加分项”而非“必需品”）

------

**一句话总结：** 从句、时态、非谓语是英语的“高级语法”，但**词法、句型结构、主谓一致、语态情态、词汇搭配**才是支撑它们的“基础语法”。地基不牢，上层建筑再华丽也容易塌。
