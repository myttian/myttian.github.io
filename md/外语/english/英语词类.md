# 非谓语动词有哪些

英语动词变为“非谓语动词”（Non-finite Verbs）主要有以下三种形式。它们在句子中不再充当谓语，而是承担名词、形容词或副词的功能：

### 1. 动词不定式 (Infinitive)

- **形式**：`to + 动词原形` (有时省略 to)
- **功能**：可作主语、宾语、表语、定语、状语或补语。
- **示例**：
    - *To learn* English is important. (作主语)
    - I want *to go*. (作宾语)
    - He came here *to study*. (作目的状语)

### 2. 动名词 (Gerund / V-ing)

- **形式**：`动词 + ing`
- **功能**：具有动词和名词的双重特征，主要作主语、宾语、表语或定语。
- **示例**：
    - *Swimming* is good exercise. (作主语)
    - I enjoy *reading*. (作宾语)
    - A *sleeping* bag. (作定语，表示用途)

### 3. 分词 (Participle)

分词分为两类，主要起形容词或副词作用：

#### 现在分词 (Present Participle)

- **形式**：`动词 + ing`
- **含义**：表示主动或进行。
- **示例**：The *crying* baby needs milk. (作定语，主动)

#### 过去分词 (Past Participle)

- **形式**：规则动词为 `-ed`，不规则动词需单独记忆
- **含义**：表示被动或完成。
- **示例**：The *broken* window was repaired. (作定语，被动/完成)

---

### 💡 快速对比总结

| 非谓语形式   | 核心特征 | 典型句法功能             |
| ------------ | -------- | ------------------------ |
| **不定式**   | `to do`  | 目的、将来、抽象概念     |
| **动名词**   | `doing`  | 习惯性动作、作为事物名称 |
| **现在分词** | `doing`  | 主动、正在进行的状态     |
| **过去分词** | `done`   | 被动、已完成的状态       |

**⚠️ 注意区分**：虽然动名词和现在分词形式相同（都是 -ing），但**动名词相当于名词**，而**现在分词相当于形容词/副词**。判断依据是看它在句中是代替“事物”还是修饰“状态”。

# 先行词

在英语语法中，**先行词**是定语从句中被关系词（如 who, which, that 等）所修饰或指代的名词、代词或短语。它之所以叫“先行”，是因为它通常出现在关系词的**前面**。

### 🔍 核心定义与结构

> **公式**：先行词 + 关系词 + 定语从句

- **例句**：The **book** *that* I bought yesterday is interesting.
    - **先行词**：book（被修饰的对象）
    - **关系词**：that（引导从句并指代 book）
    - **定语从句**：that I bought yesterday

### 📋 先行词的常见类型

| 类型         | 示例                | 对应常用关系词         |
| ------------ | ------------------- | ---------------------- |
| **人**       | the boy, my teacher | who, whom, whose, that |
| **物/动物**  | the car, the dog    | which, that, whose     |
| **时间**     | the day, the year   | when, that, which      |
| **地点**     | the city, the house | where, that, which     |
| **原因**     | the reason          | why, that, for which   |
| **整个句子** | (前面整句话的内容)  | which, as              |

### ⚠️ 关键注意点

1. **位置不一定紧邻**
   先行词和关系词之间有时会被其他成分隔开。
    - *例*：The **news** came to us *yesterday* **that** our team won. （先行词 news 被状语隔开了）
2. **决定关系词的选择**
   选择用 who 还是 which，完全取决于先行词是“人”还是“物”。
    - ✅ The **man** *who*...
    - ✅ The **car** *which*...
3. **特殊先行词**
    - **不定代词**：当先行词是 all, everything, nothing, the only 等时，关系词通常只能用 **that**。
    - **way**：当先行词是 way 表示“方式”时，关系词可用 that / in which / 省略。
    - **as 引导的非限制性定语从句**：先行词可以是整个主句，且 as 可置于句首（As is known to all...）。

### 💡 快速判断技巧

找到从句的引导词（关系词），往前找它所替代的那个词，就是先行词。如果找不到明确的名词，可能是指代前面整个句子的内容。

# have done中，分词表示被动吗

> 问题： 完成时态have done中，分词不是表示被动吗

不是的，have done里的done不表示被动，它只表示“完成”。这里的done是过去分词，但过去分词本身并不天生等于被动，它只是“完成”和“被动”两种含义的载体，具体表达哪种要看它跟谁搭配。跟have搭配时，done承担的是“完成”的功能，用来构成完成时态；真正要表达被动，得用have been done，多出来的been才是被动标记。

可以这样理解：

- have done = 主动完成：主语自己完成了某个动作，比如 `I have finished my homework.`（我已完成作业），这里的finished是“我”做的，动作是主动的。
- have been done = 被动完成：主语是动作的承受者，比如 `My homework has been finished.`（作业已被完成），be的过去分词been和done一起构成被动结构。

> 有个容易混淆的点：过去分词做定语时经常表被动，比如 `a broken window`（被打碎的窗户），让你误以为它永远等于被动。但同样的broken，放在 `I have broken the window.`（我打碎了窗户）里就完全是主动含义了，这里的broken只负责表示动作“已经完成”，不带任何被动色彩。

如果想表达被动，记住一个关键差异：have done是主动语态，have been done是被动语态，前者强调主语主动做，后者强调主语被做。 比如：

- 主动：`She has written a book.`（她写了一本书）
- 被动：`The book has been written.`（这本书已被写好）

所以，别把“过去分词”直接等同于“被动”，它的意思取决于所在的整个结构。完成时里它表完成，被动语态里它表被动，两者是靠be来区分的。

# being done放介词后

being done放在介词后，就是动名词的被动形式作介词宾语，核心作用是表达“被...”的被动含义，通常不强调“正在被...”。

比如你熟悉的例句 *He entered the room without being noticed.* 里，without 是介词，后接 being noticed，意思是“没被注意到”，只表被动，没有“正在被注意”的进行时含义。

### 📌 为什么介词后要用 being done

- 介词后只能接名词性成分：介词后面不能直接跟动词原形，也不能用过去分词 done 直接作宾语，所以需要用动名词形式，即 doing；当这个动作和逻辑主语之间是被动关系时，就要用被动形式 being done。
- 和单独用 done 的区别：being done 在介词后作宾语时，强调的是被动这个事实本身，而非动作正在进行或已经完成；而单独用过去分词 done 通常不能直接放在介词后作宾语。

### ⚠️ 容易混淆的点

- 作定语时才有“正在被...”含义：being done 只有在作后置定语（如 the bridge being built 正在被修建的桥）或宾语补足语（如 I heard the song being sung）时，才强调“正在进行且被动”。
- 作介词宾语时只表被动：像 avoid being blamed（避免被责备）、be proud of being chosen（因被选中而自豪）这类用法，都只是被动意义，没有进行时含义。

简单记：介词后看到 being done，先理解成“被...”，别自动脑补“正在被...”。

# 介词 + which = where

“介词 + which”用来指代前面的物，常见于定语从句，写起来比直接用 where、when 更正式。

### 哪些时候能用

1. 先行词是物：which指物，人则用whom，不能混用。
2. 从句里缺介词宾语：==关系代词which作介词的宾语==，介词可提前，构成“介词 + which”。
3. 想表达得更正式：口语里常把介词放从句末尾，正式写作里介词提前更规范。

### 常见介词怎么选

1. 看先行词和介词的搭配：
   - 地点：in/at/on which，可替换where。
   - 时间：on/in/at which，可替换when。
   - 原因：for which，可替换why。
2. 看从句动词或形容词的固定搭配：
   - 例：the pen with which he writes（with与write搭配）。
3. 固定短语介词不能提前：
   - 例：look after不能拆成after which，要说the baby whom she is looking after。

### 和介词加whom有什么区别

1. 指代不同：which指物，whom指人。
2. 都不能用that：介词后关系代词只能用which或whom，不能用that。
3. which不可省略：介词提前时，which或whom都不能省。

常见例句：

- This is the room in which I lived.（=where）。
- Friday is the day on which we get paid.（=when）。
- That's the reason for which he left.（=why）。
