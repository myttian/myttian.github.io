# 一类形容词（い形容词／形容词）

**核心要点**：一类形容词就是词尾以 **「い」** 结尾的形容词（如 高い、新しい、美味しい），也叫**形容词（形容詞）**。它可以直接作谓语、直接修饰名词，**变化时只变词尾的「い」**，前面的部分（词干）永远不变。与之相对的是二类形容词（な形容词／形容动词，如 静か、元気）。

> 判断小技巧：以「い」结尾 ≠ 一定是一类形容词。**「きれいだ」「嫌い」「わかい（若菜）」**等虽然以い结尾，却是な形容词或名词；而**「いい（良い）」**虽然结尾是い，却是不规则变化。

---

## 一、活用变化（以「高い」为例）

| 活用形         | 变化          | 例       | 说明                             |
| -------------- | ------------- | -------- | -------------------------------- |
| 终止形／连体形 | 原形          | 高い     | 结句、修饰名词（高い山）         |
| 连用形         | い→**く**     | 高く     | 修饰动词、接ます・て・なる・する |
| 未然形         | い→**くなか** | 高くない | 表否定                           |
| 假定形         | い→**ければ** | 高ければ | 表假定"如果贵"                   |
| 推量形         | い→**かろう** | 高かろう | 表推测（较书面）                 |
| 命令形         | い→**かれ**   | 高かれ   | 古语，现代日语基本不用           |

**注意**：一类形容词**没有**「ます形」的直接变化，礼貌体是在原形后加「です」→ 高いです（❌ 高くです）。

---

## 二、常用形式一览（背这张表最实用）

| 形式               | 构成                         | 例（高い）             | 意思            |
| ------------------ | ---------------------------- | ---------------------- | --------------- |
| 简体肯定           | 原形                         | 高い                   | 贵              |
| 简体否定           | ～くない                     | 高くない               | 不贵            |
| 简体过去           | ～かった                     | 高かった               | 曾经贵          |
| 简体过去否定       | ～くなかった                 | 高くなかった           | 当时不贵        |
| 敬体肯定           | ～いです                     | 高いです               | 贵（礼貌）      |
| 敬体否定           | ～くないです／～くありません | 高くないです           | 不贵            |
| 敬体过去           | ～かったです                 | 高かったです           | 当时贵          |
| て形（并列/原因）  | ～くて                       | 高くて買えなかった     | 又贵又…／因为贵 |
| 副词化（修饰动词） | ～く                         | 高く売る               | 高价卖          |
| 名词化             | ～さ                         | 高さ                   | 高度、高度感    |
| 变化               | ～くなる                     | 高くなる               | 变贵了          |
| 使役性变化         | ～くする                     | 値段を高くする         | 把价格弄高      |
| 假定               | ～ければ                     | 安ければ買う           | 便宜的话就买    |
| 比较               | ～より／～ほど               | 東京より大阪の方が安い | 比…更…          |
| 最高级             | いちばん～                   | いちばん高い           | 最贵            |

---

## 三、三个高频用法

**1. 修饰名词：直接用原形，不加「な」**

- 新しい本（新书）／美味しい料理（好吃的菜）／難しい問題（难题）
- 对比な形容词：静か**な**部屋、元気**な**子

**2. 作谓语：主语用「が」提示**

- この本**が**高い。（这本书贵。）
- 天气、感情等无人称句也常用が：雨が激しい。

**3. 修饰动词：变「く」**

- 早く起きる（早点起床）／ゆっくり歩く（慢慢走）／大きく開ける（大开）

---

## 四、唯一的特殊变化：「いい（良い）」

「いい」的活用要换成「よ」的词干：

| 形式   | 变化         | 例                   |
| ------ | ------------ | -------------------- |
| 原形   | いい         | いい天気だ           |
| 连用形 | **よく**     | よくできました       |
| 否定   | **よくない** | 安くはない           |
| 过去   | **よかった** | よかった！           |
| て形   | **よくて**   | 安くてよくて…        |
| 假定   | **よければ** | よければ来てください |
| 名词化 | **良さ**     | 良さに気づく         |
| 推量   | **良かろう** | 良かろう             |

另外「おおい（多い）」是**规则变化**：多く／多くない／多かった，不要误当成不规则。

---

## 五、和二类形容词的对照速记

| 项目     | 一类（い形容词） | 二类（な形容词）         |
| -------- | ---------------- | ------------------------ |
| 词尾     | い               | 无固定词尾（多为汉字词） |
| 否定     | 高**くない**     | 静か**ではない**         |
| 过去     | 高**かった**     | 静か**だった**           |
| 修饰名词 | 高い山           | 静か**な**部屋           |
| 修饰动词 | 高く売る         | 静か**に**読む           |
| 名词化   | 高さ             | 静かさ                   |
| 变化     | 高くなる         | 静かになる               |
| 假定     | 高ければ         | 静かであれば             |

---

## 六、易错点提醒

1. **❌ 高くです** → ✅ 高いです／高くありません
2. **❌ 高いな本** → ✅ 高い本（一类不加な）
3. **❌ 高くて本** → て形不能直接修饰名词，要并列或表原因
4. **「たい」不接形容词**：想说"想要贵的"用「高いのがほしい」，而不是「高きたい」
5. **形容词不能带宾语**，涉及对象时用「が」或「には」：この映画は私には難しい。

---

**一句话总结**：一类形容词 = **い结尾**，否定去い加「くない」、过去加「かった」、并列/原因变「くて」、修饰动词变「く」、修饰名词用原形，唯一的例外是「いい→よく／よかった／よければ」。

# 二类形容词（な形容词／形容动词）

**核心要点**：二类形容词就是**词干后需加「な」才能修饰名词**的那类形容词，语法上正式名称叫**形容动词（形容動詞）**，如 静か、元気、好き、簡単、きれい。它的活用**以「だ」为中心变化**（だ・でない・だった・であれば），和名词的用法几乎一致，因此也常被称作"名词性形容词"。判断方法：**去掉词尾后能加「な」修饰名词的，就是二类**（静かな部屋 ✅）；而以「い」结尾、直接修饰名词的是一类（高い山 ✅）。

---

## 一、活用变化（以「静かだ」为例）

| 活用形 | 变化           | 例                             | 说明                   |
| ------ | -------------- | ------------------------------ | ---------------------- |
| 终止形 | だ／です       | 部屋は静かだ／静かです         | 结句作谓语             |
| 连体形 | な             | 静か**な**部屋                 | 修饰名词               |
| 连用形 | に／で         | 静か**に**読む／静か**で**     | 修饰动词／中顿并列     |
| 未然形 | で（は）       | 静か**ではない**               | 表否定                 |
| 假定形 | なら・であれば | 静か**なら**／静か**であれば** | 表假定                 |
| 命令形 | で（あれ）     | 静かにしろ                     | 现代基本用副词形式表达 |

关键：**修饰名词用「な」，修饰动词用「に」**，这是二类形容词最容易记混也最容易考的一点。

---

## 二、常用形式一览（最实用的一张表）

| 形式               | 构成                               | 例（静か）                 | 意思                   |
| ------------------ | ---------------------------------- | -------------------------- | ---------------------- |
| 简体肯定           | ～だ                               | 静かだ                     | 安静                   |
| 简体否定           | ～ではない／～じゃない             | 静かではない               | 不安静                 |
| 简体过去           | ～だった                           | 静かだった                 | 当时安静               |
| 简体过去否定       | ～ではなかった                     | 静かではなかった           | 当时不安静             |
| 敬体肯定           | ～です                             | 静かです                   | 安静（礼貌）           |
| 敬体否定           | ～ではありません／～じゃありません | 静かではありません         | 不安静                 |
| 敬体过去           | ～でした                           | 静かでした                 | 当时安静               |
| 敬体过去否定       | ～ではありませんでした             | 静かではありませんでした   | 当时不安静             |
| て形（并列/原因）  | ～で                               | 静かで快適だ               | 又安静又舒适／因为安静 |
| 副词化（修饰动词） | ～に                               | 静かに話す                 | 小声说话               |
| 名词化             | ～さ                               | 静かさ                     | 安静程度               |
| 变化               | ～になる                           | 静かになる                 | 变安静了               |
| 使役性变化         | ～にする                           | 部屋を静かにする           | 让房间安静下来         |
| 假定               | ～なら／～であれば                 | 静かなら勉強できる         | 如果安静的话           |
| 比较               | ～より／～ほど                     | 図書館より教室の方が静かだ | 比…更安静              |
| 最高级             | いちばん～                         | いちばん静かな場所         | 最安静的地方           |

---

## 三、三个高频用法

**1. 修饰名词：必须加「な」**

- 元気**な**子／簡単**な**問題／きれい**な**花／有名**な**作家／大切**な**人

**2. 作谓语：主语用「が」或主题「は」**

- この部屋**は**静かだ。（这个房间很安静。）
- 私は猫**が**好きだ。（我喜欢猫。——「好き」是二类形容词，对象用が）

**3. 修饰动词：变「に」**

- 丁寧に書く（认真地写）／ゆっくり歩く／はっきり言う／大切に扱う

---

## 四、常见二类形容词分类速记

| 类别       | 例词                                                         |
| ---------- | ------------------------------------------------------------ |
| 状态・性质 | 静か、にぎやか、きれい、うるさい、簡単、複雑、大切、立派     |
| 感情・好恶 | 好き、嫌い、苦手、得意、安心、不満、残念、寂しい※            |
| 能力・状态 | 上手、下手、得意、苦手、元気、丈夫、不器用                   |
| 评价       | 有名、偉い※、立派、立派、便利、不便、重要、珍                |
| 外来语     | 元気、静か、簡単、複雑、便利、安全、危険、有名、活発、積極的 |

带 ※ 的「偉い」「寂しい」其实是一类形容词（以い结尾），注意别混进二类。

---

## 五、易错点提醒

1. **❌ 静か部屋** → ✅ 静か**な**部屋（漏「な」是最常见错误）
2. **❌ 静か読む** → ✅ 静か**に**読む（修饰动词要用に）
3. **❌ 静かいです** → ✅ 静か**です**（二类不加い）
4. **❌ 静かでないです**（口语可说じゃないですが书面不自然）→ 推荐 **静かではありません**
5. **「好き・嫌い・上手・下手・得意・苦手」的对象用「が」**：私は音楽**が**好きだ。（❌ を好きだ）
6. **「きれい」是二类**（来自「奇麗」），虽然以い结尾：きれい**な**服、きれい**に**掃除する。
7. **「だめ」「だめだ」** 也按二类处理：だめだ／だめで／だめな／だめにしない。

## 六、一类 vs 二类 对照速查

| 项目     | 一类（い形容词） | 二类（な形容词）         |
| -------- | ---------------- | ------------------------ |
| 词尾     | い               | 无固定词尾（多为汉字词） |
| 修饰名词 | 高い山（直接接） | 静か**な**部屋           |
| 修饰动词 | 高く売る         | 静か**に**読む           |
| 否定     | 高**くない**     | 静か**ではない**         |
| 过去     | 高**かった**     | 静か**だった**           |
| 过去否定 | 高**くなかった** | 静か**ではなかった**     |
| 敬体     | 高いです         | 静かです                 |
| て形     | 高**くて**       | 静か**で**               |
| 名词化   | 高さ             | 静かさ                   |
| 变化     | 高くなる         | 静かになる               |
| 假定     | 高ければ         | 静かなら／であれば       |

---

**一句话总结**：二类形容词 = **加「な」修饰名词、加「に」修饰动词**，否定用「ではない」、过去用「だった」、并列用「で」、变化用「になる」，活用逻辑和名词加「だ」完全一致。

# ==日语动词有哪几段==

日语动词按**活用变化规律**分为三大类：**五段活用动词、一段活用动词、变格活用动词**。这是学日语动词变形（ます形、て形、可能形、被动形等）的基础，先分清类别，后面所有变形规则才不会乱。

## 一、五段活用动词（又称「う动词」）

词尾是 **う、く、ぐ、す、つ、ぬ、ぶ、む、る** (==基本形词尾在「う段」==)这九个假名之一，且变化时词尾在这五个元音段（あ・い・う・え・お段）之间移动，所以叫"五段"。

| 词尾 | 例词           | ます形   |
| ---- | -------------- | -------- |
| う   | 会う（あう）   | 会います |
| く   | 書く（かく）   | 書きます |
| ぐ   | 泳ぐ（およぐ） | 泳ぎます |
| す   | 話す（はなす） | 話します |
| つ   | 待つ（まつ）   | 待ちます |
| ぬ   | 死ぬ（しぬ）   | 死にます |
| ぶ   | 遊ぶ（あそぶ） | 遊びます |
| む   | 読む（よむ）   | 読みます |
| る   | 作る（つくる） | 作ります |

**判断技巧**：把词尾换成「い」段假名后如果**能构成有意义的词**，就是五段动词。例如「書く」→「書い」（书写，成立）→ 五段；而「食べる」→「食べい」不成立 → 一段。

## 二、一段活用动词（又称「る动词」）

> 词尾必须是“る”，且“る”前面的假名要在“い段”或“え段”。变形时通常直接去掉“る”接后续词

==词尾都是「る」==，但「る」前面的假名固定不变，只在「る／れ／ろ」之间变化，所以叫"一段"。又分两类：

**1. 上一段活用（上一段る动词）**——「る」前是 **い段** 假名

- 食べる（たべる）、見る（みる）、起きる、寝る、着る、開ける、閉める、教える

**2. 下一段活用（下一段る动词）**——「る」前是 **え段** 假名，数量很少，常用的大概只有：

- 得る（える）、蹴る（ける）、似る（にる）、肥える、携える

> 注意：像「帰る（かえる）」「入る（はいる）」「走る（はしる）」「知る（しる）」「切る（きる）」这些虽然词尾是 る、前面也是い段或え段，但它们是**五段动词**，属于必须背的例外。

## 三、变格活用动词（不规则动词）

只有两个，完全不遵守上面的规律，必须单独记：

- **する**（做）→ します、して、した、できる…
- **来る（くる）**（来）→ 来ます（きます）、来て（きて）、来た（きた）

## 快速判断流程

1. 词尾不是「る」→ 五段动词。
2. 词尾是「る」→ 把「る」换成「い」：
- 换后不成词（如 食べい、見い）→ 一段动词
- 换后成词（如 帰い、走り）→ 五段动词
3. 是「する」或「来る」→ 变格动词。

顺带一提，与动词并列的还有形容词（い形容词）和形容动词（な形容词），它们不属于"段"的分类体系，变形规则另有一套。

# 日语动词「==五段活用==」（五段活用動詞）

**核心要点**：五段活用动词的**词尾假名会在あ・い・う・え・お这"五段"上变化**，因此得名。它属于**自立活用**中的"ウ段结尾"动词，也就是我们常说的**一类动词（u动词）**。判断方法很简单：**辞书形（原形）以 う、く、ぐ、す、つ、ぬ、ぶ、む、る 结尾**，且以「る」结尾时，「る」前面必须是**あ段或う段**的假名（如 作る、乗る）；若前面是い段或え段（如 食べる、見る），则是一段动词。

---

## 一、六种活用形（以「書く」为例）

| 活用形 | 词尾变化 | 例（書く） | 主要用途                                                     |
| ------ | -------- | ---------- | ------------------------------------------------------------ |
| 未然形 | あ段     | 書**か**   | ＋ない／ずに／れる・られる（被动）／せる・させる（使役）／れる（可能）／う・よう（意志） |
| 連用形 | い段     | 書**き**   | ＋ます／たい／て／た／ながら／すぎる                         |
| 終止形 | う段     | 書**く**   | 句末终止、辞书形（原形）                                     |
| 連体形 | う段     | 書**く**   | 修饰名词（書く人＝写字的人）                                 |
| 仮定形 | え段     | 書**け**   | ＋ば（如果……）                                               |
| 命令形 | え段     | 書**け**   | 命令（書け！＝写！）                                         |

现代日语中，終止形与連体形同形，仮定形与命令形同形，所以实际只需记 **あ・い・う・え** 四段。

| う   | 買う | 買わ（ない）       | 買い（ます）   | 買**って** | 買**った** | 買え   | 買える |
| く   | 書く | 書か               | 書き           | 書**いて** | 書**いた** | 書け   | 書ける |
| ぐ   | 泳ぐ | 泳が               | 泳ぎ           | 泳**いで** | 泳**いだ** | 泳げ   | 泳げる |
| す   | 話す | 話さ               | 話し           | 話**して** | 話**した** | 話せ   | 話せる |
| つ   | 待つ | 待た               | 待ち           | 待**って** | 待**った** | 待て   | 待てる |
| ぬ   | 死ぬ | 死な               | 死に           | 死**んで** | 死**んだ** | 死ね   | 死ねる |
| ぶ   | 遊ぶ | 遊ば               | 遊び           | 遊**んで** | 遊**んだ** | 遊べ   | 遊べる |
| む   | 読む | 読ま               | 読み           | 読**んで** | 読**んだ** | 読め   | 読める |
| る   | 作る | 作ら               | 作り           | 作**って** | 作**った** | 作れ   | 作れる |

**て形・た形的音便规律（背这个就够）**

- **い音便**：く → いて、ぐ → いで（書く→書いて、泳ぐ→泳いで）
- **ん音便**：ぬ・ぶ・む → んで（死ぬ→死んで、遊ぶ→遊んで、読む→読んで）
- **促音便**：う・つ・る → って（買う→買って、待つ→待って、作る→作って）
- **無音便**：す → して（話す→話して）

1. **言う**：虽属五段，但て形是「言って／言った」（わ＋て→って），不是「言いて」。

ます形是五段动词活用的一种具体形式，两者是“活用类型”和“具体变形”的关系。简单说，五段动词变ます形时，要把词尾的う段假名变成同一行的い段假名，再加上ます。

比如「書く」（かく）→「書きます」（かきます），「読む」（よむ）→「読みます」（よみます），「買う」（かう）→「買います」（かいます）。

## 为什么这么变

五段动词的“五段”指的是词尾会在あ、い、う、え、お五个段上变化，ます形（连用形）就是其中“い段”这一种变形。 所以不是五段动词和ます形有特殊关联，而是所有五段动词的ます形都遵循这一条规律。

## 两个容易踩的坑

- 特殊五段动词：像「帰る」「切る」「知る」「走る」「入る」这类词，虽然看起来像一段动词（以る结尾且前一个假名在い段或え段），但它们是五段动词，变ます形时仍然要变成い段假名。比如「帰る」→「帰ります」，「知る」→「知ります」。
- ラ行特殊五段动词：还有极少数像「なさる」「くださる」「いらっしゃる」这样的敬语动词，变ます形时不是变成い段，而是直接在词干后加「い」再加「ます」，比如「なさる」→「なさいます」。

## 怎么判断是不是五段动词

判断一个动词是不是五段，主要看它的基本形（辞书形）：

- 以「る」以外的う段假名结尾的，基本都是五段动词，比如「書く」「話す」「立つ」。
- 以「る」结尾的，要看「る」前面的假名：不在い段或え段上，就是五段动词，比如「割る」「祈る」；在い段或え段上，通常是一段动词，但有少数例外（上面提到的「帰る」「切る」等）需要单独记。

日语中只有**动词**（以及形容词、形容动词）有"活用形"的分类， 以下为你系统梳理日语动词的活用形体系：

### 一、 按动词类别分三大活用类型

这是学习所有变形的基础框架：

| 活用类型     | 别称                  | 核心特征                           | 典型例词                         |
| ------------ | --------------------- | ---------------------------------- | -------------------------------- |
| **五段活用** | ==う动词== / I类动词  | 词尾在あ・い・う・え・お五段间变化 | 書く、話す、待つ、読む、作る     |
| **一段活用** | ==る动词== / II类动词 | 词尾固定为「る」，仅る/れ/ろ变化   | 食べる（上一段）、得る（下一段） |
| **变格活用** | III类动词             | 完全不规则，仅两个                 | する、来る（くる）               |

> ⚠️ **易错提醒**：「帰る」「入る」「走る」「知る」「切る」等虽以「る」结尾且前接い/え段假名，但属于**五段动词**，需单独记忆。

### 二、 按语法功能分六大基本活用形

无论哪类动词，都对应这六种形态，用于接续不同助动词或表达特定语法： (自己补充，还有个推量形)

1. **未然形**：后接「ない」（否定）、「れる/られる」（被动/可能）、「せる/させる」（使役）。
    - 五段：あ段（書か-ない）
    - 一段：去掉る（食べ-ない）
    - 变格：し-ない / こ-ない
2. **连用形**：后接「ます」（礼貌体）、「て/た」（中顿/过去）、「たい」（愿望）。
    - 五段：い段（書き-ます）
    - 一段：去掉る（食べ-ます）
    - 变格：し-ます / き-ます
3. **终止形**：即词典原形，用于句尾结句（書く、食べる、する、来る）。
4. **连体形**：修饰体言（名词），现代日语中与终止形同形（書く本、食べる人）。
5. **假定形**：后接「ば」表示条件。
    - 五段：え段（書け-ば）
    - 一段：去掉る+れば（食べ-れば）
    - 变格：すれ-ば / くれ-ば
6. **命令形**：表示强指令。
    - 五段：え段（書け！）
    - 一段：去掉る+ろ/よ（食べろ！）
    - 变格：しろ！ / こい！

- **形容词/形容动词也有活用形**（如い形容词的「高くない」「高ければ」），但与动词体系独立，不可混淆。
- **现代日语简化趋势**：口语中未然形与连用形的界限逐渐模糊（如「書かない」实际由连用形「書き」音变而来），但传统六段分类仍是理解书面语和古典日语的核心。

## 日语活用形

日语的“活用形”是指单词为了接续助动词、助词或表达不同语法功能而发生词尾变化的形态。需要特别明确的是，**只有动词、形容词（い形容词）和形容动词（な形容词）这三类词有活用，名词没有活用**。

以下是日语三大词类的活用形完整体系：

### 一、 动词的六大基本活用形

这是日语语法的骨架，所有动词变形都基于这六种形态：

| 活用形     | 核心功能                                     | 五段动词 (書く) | 一段动词 (食べる) | サ变 (する)  | カ变 (来る) |
| ---------- | -------------------------------------------- | --------------- | ----------------- | ------------ | ----------- |
| **未然形** | 接「ない」(否定)、「れる/られる」(被动/可能) | 書か            | 食べ              | し / さ / せ | こ          |
| **连用形** | 接「ます」「て」「た」「たい」               | 書き            | 食べ              | し           | き          |
| **终止形** | 句尾结句（词典原形）                         | 書く            | 食べる            | する         | 来る        |
| **连体形** | 修饰名词（现代日语=终止形）                  | 書く            | 食べる            | する         | 来る        |
| **假定形** | 接「ば」表条件                               | 書け            | 食べれ            | すれ         | くれ        |
| **命令形** | 强指令                                       | 書け            | 食べろ            | しろ         | こい        |

> 💡 **注意**：サ变动词「する」的未然形有三种形态，分别用于不同接续：「しない」（否定）、「される」（被动）、「させる」（使役）。

### 二、 形容词（い形容词）的活用形

い形容词的活用相对简单，核心是词尾「い」的变化：

- **未然形**：から → 接「ない」（高くない）※现代口语多用连用形「く」+ない
- **连用形**：く / かっ → 「高いです」（礼貌）、「高かった」（过去）
- **终止形**：い → 句尾结句（高い）
- **连体形**：い → 修饰名词（高い山）
- **假定形**：けれ → 接「ば」（高ければ）
- **命令形**：かれ → 古语/书面残留，现代几乎不用

### 三、 形容动词（な形容词）的活用形

形容动词本质是“名词+だ”，其活用实际上是断定助动词「だ」的活用：

- **未然形**：だろ → 接「う」（推量：静かだろう）
- **连用形**：に / で / だっ → 「静かに」（副词用法）、「静かで」（中顿）、「静かだった」（过去）
- **终止形**：だ → 句尾结句（静かだ）
- **连体形**：な → 修饰名词（静かな町）⚠️ 这是与名词的核心区别
- **假定形**：なら → 接「ば」（静かならば）
- **命令形**：无（形容动词不能表示命令）

日语语法除了活用形，主要还有助词、助动词、句法结构这三大块，它们和活用形一起构成了日语语法的核心框架。

### 核心板块

1. 助词体系：日语助词数量不多（不到50个），但决定了句子的语义方向和词与词之间的关系。比如 `は` 和 `が` 的区别、`を` 表示宾语、`に` 表示方向或时间点、`で` 表示方式或场所等。助词本身没有活用变化，属于附属词。
2. 助动词：接在活用形后面，赋予句子额外意义。比如 `ない`（否定）、`れる/られる`（被动/可能/尊敬）、`せる/させる`（使役）、`たい`（愿望）、`そうだ`（样态/传闻）、`ようだ`（比况）等。助动词本身也有活用，有的像动词，有的像形容词，有的属于特殊活用。
3. 句法结构：即句子成分的排列规则和组合方式。日语是主宾谓（SOV）结构，修饰成分位于被修饰词之前。句式核心有三类：基本主宾谓、`は/が` 双层结构（话题+焦点）、`て形` 连接多个动作或原因结果。

### 补充知识

- 句型：基于语法规则形成的固定结构模板，比如 `～なければならない`（必须）、`～たり～たりする`（又…又…）、`～たら`（如果…之后）等。句型是语法规则的具体应用，需要严格遵循语法规则才能成立。
- 两大语法体系：日本语法教学存在“学校语法”和“教育语法”两套体系。学校语法注重形态分类（如五段动词、一段动词），教育语法从 `ます形` 导入、按语义划分动词为三类。不同教材术语可能不同，但本质相通。

> 日语动词的五大态： “可能态”、“[被动态](https://baike.baidu.com/item/被动态/0?fromModule=lemma_inlink)”、“[使役态](https://baike.baidu.com/item/使役态/0?fromModule=lemma_inlink)”、“[自发态](https://baike.baidu.com/item/自发态/0?fromModule=lemma_inlink)”“[被役态](https://baike.baidu.com/item/被役态/0?fromModule=lemma_inlink)”

日语的“语态”（Voice）主要指动词通过活用变化，来表示主语与动作之间关系的语法范畴。与英语类似，日语的核心语态包括**主动、被动、使役、使役被动**四种，此外还有表示自发性质的**自发态**和表示尊重的**尊敬/谦让语态**。

以下是日语六大核心语态的系统梳理：

### 一、 四大基础语态对照表

| 语态           | 构成方式                     | 核心语义                      | 例句（以「書く」为例）         |
| -------------- | ---------------------------- | ----------------------------- | ------------------------------ |
| **主动态**     | 动词原形/ます形              | 主语主动执行动作              | 先生が論文を**書く**。         |
| **被动态**     | 未然形 + れる/られる         | 主语承受动作（受害/客观叙述） | 論文が先生に**書かれる**。     |
| **使役态**     | 未然形 + せる/させる         | 主语让/强迫他人做某事         | 学生に論文を**書かせる**。     |
| **使役被动态** | 未然形 + せられる/させられる | 主语被迫/不得不做某事         | 学生は論文を**書かせられる**。 |

⚠️ **关键提醒**：五段动词的使役被动态在口语中常简化为「書かされる」（去掉「せ」），但一段动词和变格动词必须用完整形式「食べさせられる」「させられる」。

### 二、 各语态的核心用法与难点

#### 1. 被动态（受身）

- **直接被动**：动作对象作主语，动作执行者用「に/から」标记。
    - 彼は上司**に**叱られた。（他被上司骂了。）
- **间接被动（迷惑被动）**：主语并非动作直接对象，但因他人动作而受到负面影响。**这是日语特有的语态，中文无对应表达**。
    - 雨**に**降られた。（因下雨而遭殃，如淋湿、计划取消）
    - 赤ちゃん**に**泣かれた。（因婴儿哭闹而心烦）
- **客观叙述被动**：隐藏动作执行者，用于新闻、论文等正式文体。
    - この小説は19世紀に**書かれた**。（这部小说写于19世纪。）

#### 2. 使役态（使役）

- **强制使役**：上级对下级、长辈对晚辈，带有强迫意味。
    - 母は子供に野菜を**食べさせた**。（妈妈逼孩子吃蔬菜。）
- **许可使役**：允许他人做某事，常与「てもらう」连用表委婉请求。
    - 写真を撮らせて**いただけますか**？（能让我拍张照吗？）
- **诱发使役**：描述某种状态引发他人的情感或反应（多用于文学）。
    - その映画は観客を**泣かせた**。（那部电影让观众落泪。）

#### 3. 使役被动态（使役受身）

- **被迫做不愿做的事**：强调主语的无奈、痛苦或不情愿。
    - 残業を**させられた**。（被迫加班。）
- **习惯性被迫**：描述长期处于被支配的状态。
    - 子供の頃、毎日ピアノを**弾かせられていた**。（小时候每天都被迫弹钢琴。）

### 三、 特殊语态补充

- **自发态**：表示动作/情感不由自主地发生，多为固定表达。
    - 故郷が**偲ばれる**。（不由得怀念故乡。）
    - 涙が**こぼれる**。（眼泪不由自主地流下。）
- **尊敬语态**：通过「れる/られる」或专用敬语动词抬高动作主体。
    - 先生が**来られる**。＝ 先生が**いらっしゃる**。
- **谦让语态**：通过「お/ご～する」或专用谦让动词降低自身动作。
    - 私が**お持ちします**。＝ 私が**参ります**。

### 💡 学习建议

1. **优先掌握被动与使役被动**：这两者是N3-N2考试高频考点，也是日常交流中最易出错的语态。
2. **区分“に”的语义**：被动句中「に」表动作执行者，使役句中「に」表被使役对象，需结合语境判断。
3. **避免过度使用被动**：日语被动多含“受害/无奈”色彩，中性叙述优先用主动句，仅在需要强调受事者或隐藏施事者时才用被动。

若需要某语态的专项变形练习、易错辨析题，或想了解特定场景（如商务邮件、学术论文）中的语态使用规范，可随时告知。

# 动词

## ==区分一类、二类、三类动词==

日语里的一类、二类、三类动词，核心区别在于词尾特征和变形规则，记住下面的判断步骤就能快速区分，还能避开常见的例外坑。

### 🔍 先理清术语对应关系

不同教材叫法不同，先统一概念：

- 一类动词 = 五段动词
- 二类动词 = 一段动词
- 三类动词 = サ变动词 + カ变动词 

---

1. ### 一类动词（五段动词）

   它是日语里最常见的动词类型，变形规则相对复杂。

- 核心识别规则：
  1.  动词原形不以「る」结尾，直接归为一类，比如「買う」「書く」「話す」。
  2.  即使以「る」结尾，「る」前面的假名不在「い段」或「え段」上，也是一类，比如「終わる」「掛かる」。
- 变形特点：词尾会在あいうえお五个段上变化，比如「行く」的变形会出现行か、行き、行く、行け等不同形态。
- 高频例外：有20多个特殊词，虽然「る」前假名在い/え段，但实际是一类动词，比如「帰る」「切る」「知る」「走る」「要る」，这类词需要单独记忆。

---

2. ### 二类动词（一段动词）

   它的变形规则最简单，是初学者最容易掌握的一类。

- 核心识别规则：
  1.  必须以「る」结尾，这是硬性条件。
  2.  「る」前面的假名一定在「い段」或「え段」上，比如「食べる（たべる）」「教える（おしえる）」「見る（みる）」「起きる（おきる）」。
- 变形特点：所有变形都直接去掉词尾的「る」，再加上对应后缀即可，比如「食べる」变ます形就是「食べます」，变て形就是「食べて」。
- 分类细节：还能细分为上一段动词（る前在い段，如「見る」）和下一段动词（る前在え段，如「食べる」），但两者变形规律完全一致，不用分开记。

---

3. ### 三类动词（不规则动词）

   这类动词数量极少，但变形完全不按常规规则走，需要单独硬背。

- 核心识别规则：
  1.  カ变动词：全日语只有一个词——「来る（くる）」，表示“来”。
  2.  サ变动词：核心词是「する（する）」，表示“做”；所有动作性名词后面加「する」，都属于这类动词，比如「勉強する」「結婚する」「散歩する」。
- 变形特点：没有统一规律，比如「来る」变ます形是「来（き）ます」，变ない形是「来（こ）ない」，只能逐个记牢。

---

### 📋 快速区分流程图

1.  先看是不是「来る」或带「する」的词 → 是，直接归为三类动词。
2.  再看是否以「る」结尾，且る前假名在い/え段 → 是，大概率是二类动词，排除那20多个特殊一类动词即可。
3.  剩下的所有动词，全部属于一类动词。

## 动词分类

日语动词的分类是掌握所有活用变形的基础。根据不同的语法体系和学习阶段，主要有**三种分类维度**。对于学习者而言，最核心、最实用的是按“词尾变化规律”进行的三分法。

### 一、 按活用规律分类（学习核心）

这是教材和考试中最通用的分类方式，直接决定了动词如何变形。

| 类别         | 别名              | 判定特征                                             | 典型示例                                             | 备注                             |
| ------------ | ----------------- | ---------------------------------------------------- | ---------------------------------------------------- | -------------------------------- |
| **五段动词** | I类 / グループ1   | 词尾在「う段」（く、す、つ、ぬ、む、る、ぐ、ぶ、ぷ） | 書く、話す、待つ、死ぬ、読む、帰る、泳ぐ、遊ぶ、買う | 数量最多，变形规则最复杂         |
| **一段动词** | II类 / グループ2  | 词尾为「る」，且「る」前一个假名在「い段」或「え段」 | 見る(い段)、食べる(え段)                             | 变形规则统一，去掉「る」即可接续 |
| **变格动词** | III类 / グループ3 | 仅两个词：「する」「来る（くる）」及其复合词         | 勉強する、留学する、来る                             | 完全不规则，需单独记忆           |

#### ⚠️ 最大难点：特殊五段动词（例外动词）

有一部分动词虽然词尾是「る」且「る」前为「い/え段」，**看起来像一段动词，但实际上是五段动词**。这类词没有绝对规律，必须作为特例单独记忆。高频词包括：

- **帰る（かえる）**：回家 → 五段（帰ります，非「帰ます」）
- **入る（はいる）**：进入 → 五段（入ります）
- **走る（はしる）**：跑 → 五段（走ります）
- **要る（いる）**：需要 → 五段（要ります）※注意与一段动词「居る（いる）」区分
- **切る（きる）**：切 → 五段（切ります）
- **練る（ねる）**：锻炼/推敲 → 五段（練ります）
- **減る（へる）**：减少 → 五段（減ります）
- **喋る（しゃべる）**：说话 → 五段（喋ります）

> **快速验证法**：将动词变为「ない形」。若「る」前元音发生变化（如「帰る→帰らない」），则为五段；若直接去「る」加「ない」（如「食べる→食べない」），则为一段。

### 二、 按语义功能分类（句法核心）

此分类决定句子结构，尤其是助词的使用和能否构成被动/使役态。

1. **自动词（不及物动词）**
    - 描述主语自身的动作或状态变化，不涉及外部对象。
    - 搭配助词「が/を（表移动场所）」。
    - 例：行く、寝る、咲く、壊れる（物品自己坏了）
    - **不能构成直接被动语态**（但可有迷惑被动）。
2. **他动词（及物动词）**
    - 描述主语对宾语施加的动作。
    - 搭配助词「を」。
    - 例：食べる、読む、開ける、壊す（人为弄坏）
    - **可构成直接被动语态**。
3. **成对自他动词**
    - 许多动词存在自动词与他动词的对应关系，意义相关但用法不同。
    - 例：開く（自动）↔ 開ける（他动）；落ちる（自动）↔ 落とす（他动）

### 三、 按学校文法分类（学术/母语者体系）

这是日本国语教育中的传统分类，共七种，主要用于理解古典日语和语言学分析，N1以上或专业学习者需了解：

- **四段活用**：对应现代五段动词主体（書く、話す等）
- **上一段活用**：词尾「る」前为「い段」（見る、起きる）
- **下一段活用**：词尾「る」前为「え段」（食べる、受ける）
- **上二段活用**：古语残留，现代已并入上一段（如「似る」古形「にる」）
- **下二段活用**：古语残留，现代已并入下一段（如「受く」古形「うく」）
- **サ行变格活用**：「する」及其复合词
- **カ行变格活用**：「来る」

### 📌 学习路径建议

1. **初级阶段**：牢固掌握“三类分法”，重点攻克特殊五段动词的辨识。
2. **中级阶段**：系统学习自他动词配对，建立正确的助词搭配直觉。
3. **高级/专业阶段**：了解学校文法七类分法，打通古今日语活用的演变逻辑。

若需要特殊五段动词完整清单、自他动词配对表，或针对某一分类的专项练习，可随时告知。

## 二类动词

最后一个音位于え段的二类动词，指的是把「ます形」去掉「ます」后，剩下的最后一个假名落在え段上的动词，这类动词在日语里也叫==一段动词==。

这类动词的典型特征是：==原形（基本形）以「る」结尾==，且「る」前面的假名在え段上（如「食べる」「教える」）。

🎯 常见例子

- 食べる（たべる）：吃
- 教える（おしえる）：教
- 起きる（おきる）：起（床）——注意这个是例外，虽然「き」在い段，但仍算二类动词。
- 見る（みる）：看——同样是例外，い段结尾但属于二类动词。

> 需要留意的是，大部分以え段结尾的是二类动词，但存在「起きます」「見ます」这类特殊二类动词，它们最后一个音在い段，却仍归为二类动词。

## ==三类动词==

日语中的“三类动词”（III类动词 / グループ3 / 变格动词）是日语动词体系中**数量最少但使用频率极高、变形最不规则**的一类。它仅包含两个核心词及其派生词，是所有日语学习者在初学阶段就必须单独死记硬背的内容。

### 🎯 核心构成

三类动词由以下两部分组成：

| 核心词           | 汉字/假名    | 基本含义 | 备注                               |
| ---------------- | ------------ | -------- | ---------------------------------- |
| **サ行变格动词** | する         | 做、干   | 可独立使用，也可接名词构成复合动词 |
| **カ行变格动词** | 来る（くる） | 来       | 仅此一词，无其他同类               |

> ⚠️ **关键提醒**：「する」和「来る」的变形**完全不遵循**五段或一段动词的规则，没有任何规律可循，必须逐条记忆。

### 🔤 核心活用变形对照表

以下是三类动词在基础语法中最常用的六种变形，也是考试和日常交流的高频考点：

| 变形名称  | する       | 来る（くる）         | 常见用途                     |
| --------- | ---------- | -------------------- | ---------------------------- |
| ます形    | します     | 来ます（きます）     | 礼貌体、句子结句             |
| て形      | して       | 来て（きて）         | 连接句子、请求、==进行时==   |
| ない形    | しない     | 来ない（こない）     | 否定、禁止、条件             |
| た形      | した       | 来た（きた）         | ==过去式、完成体==、修饰名词 |
| 可能态    | できる     | 来られる（こられる） | 表示能力或可能性             |
| 被动/尊敬 | される     | 来られる（こられる） | 被动语态或抬高对方动作       |
| 使役态    | させる     | 来させる（こさせる） | 让/强迫某人来                |
| 命令形    | しろ／せよ | 来い（こい）         | 强烈指令（男性用语居多）     |
| 意志形    | しよう     | 来よう（こよう）     | 提议、劝诱                   |
| 假定形    | すれば     | 来れば（くれば）     | 假设条件                     |

#### 💡 「来る」的特殊读音注意

- **原形/辞书形**：读作「くる」（ku-ru）
- **除原形外的几乎所有变形**：词干变为「き」（ki），如「きます」「きた」「こない」
- **唯一例外**：命令形「来い」读作「こい」（ko-i），而非「きい」

### 📚 サ变动词的两大类型

「する」在实际使用中分为两种形态，语义和用法略有差异：

1. **独立动词「する」**
    - 表示泛指的“做”某个动作，宾语用「を」标记。
    - 例：勉強**を**する（学习）、料理**を**する（做饭）
2. **复合サ变动词（名词+する）**
    - 汉语词汇或外来语直接加「する」构成动词，此时「を」可省略。
    - 例：勉強する、旅行する、コピーする、メールする
    - ⚠️ **易错点**：并非所有名词都能加「する」。只有具备“动作性”的名词才可构成サ变动词，如「テーブルする」「空する」是错误的表达。

### ⚠️ 高频易混淆辨析

- **「する」vs「している」**
    - 「する」强调动作的发生或习惯性行为；「している」强调动作正在进行或状态的持续。
    - 例：結婚する（结婚这个动作） vs 結婚している（已婚状态）
- **「来る」的可能态 vs 被动态**
    - 两者形式完全相同，均为「来られる（こられる）」，需依靠上下文区分。
    - 可能：明日、学校に来られますか？（明天能来学校吗？）
    - 被动：先生が教室に来られた。（老师来到教室了【尊敬】/ 被老师来到教室【被动，极少用】）
- **三类动词 ≠ “以る结尾的动词”**
    - 很多初学者误以为词尾是「る」就是二类动词，但「来る」是三类，「帰る」「入る」等是特殊五段动词。**判断类别不能只看词尾，必须结合整体形态记忆**。

### 📌 学习建议

1. **制作专属卡片**：将「する」和「来る」的所有变形写在一张卡片上，随身携带反复背诵，直到形成肌肉记忆。
2. **优先掌握高频变形**：初期重点攻克「ます・て・ない・た」四种基础变形，可能态、使役态等可在学到对应语法时再强化。
3. **通过例句记忆**：不要孤立背变形，将其放入短句中学习，如「宿題をしてから寝ます」「友達が来ない」，同时巩固语义和用法。
4. **警惕“伪三类”**：遇到不确定的动词，先查词典确认类别，避免凭感觉归类导致后续变形全盘错误。

若需要三类动词的专项填空练习、与一二类动词的混合辨析题，或想了解特定复合サ变动词的用法，可随时告知。

## 日语动词分为3类

[日语动词分为3类_百度搜索](https://www.baidu.com/s?ie=UTF-8&wd=%E6%97%A5%E8%AF%AD%E5%8A%A8%E8%AF%8D%E5%88%86%E4%B8%BA3%E7%B1%BB)  

日语动词在学习教材中主要分为一类动词、二类动词、三类动词，分类依据是词尾变化规律。

### 📚 怎么判断一类动词

一类动词也叫五段动词，词尾通常在五十音图的“う段”。如果动词不以“る”结尾，或者以“る”结尾但前面的假名不在“い段”或“え段”，基本都是一类。例如：買う（买）、書く（写）、読む（读）。这类动词变形时词尾会在五个段位上变化。

### 🥢 怎么判断二类动词

二类动词也叫一段动词，特征是词尾必须是“る”，且“る”前面的假名要在“い段”或“え段”。变形时通常直接去掉“る”接后续词。例如：食べる（吃）、起きる（起床）、見る（看）。但要注意，帰る、走る、入る等虽然符合外形，实际是一类动词，需要特殊记忆。

### 🔢 三类动词有哪些

三类动词只有两个不规则变化的词，分别是“する”（做）和“来る”（来）。“する”还可以接在名词后面构成新动词，如勉強する（学习）。

# 基本形变ない形

[日语动词变化规则（ます形、て/た形、ない形、ば形）](https://zhuanlan.zhihu.com/p/624114553)  

日语动词从基本形（辞书形）变成 ない形（否定形），核心是先判断动词类型，再按规则变词尾。下面按三类动词分别说明，附常见例子。

### 变形规则

1. 一类动词（五段动词）：把词尾的 `う` 段假名变成同行 `あ` 段假名，再加 `ない`。
   - 词尾是 `う` 时，变成 `わ`（不是 `あ`），这是唯一需要注意的特殊点。
   - 例：`書く→書かない`、`読む→読まない`、`買う→買わない`、`話す→話さない`、`待つ→待たない`、`死ぬ→死なない`。

2. 二类动词（一段动词）：去掉词尾 `る`，直接加 `ない`。
   - 例：`食べる→食べない`、`見る→見ない`、`起きる→起きない`、`寝る→寝ない`。

3. 三类动词（カ变、サ变）：只有两个词，直接记。
   - `来る（くる）→来ない（こない）`；`する→しない`（如 `勉強する→勉強しない`）。

> 需要注意：`ない形` 是动词的未然形之一，后面可以接 `ない`、`ぬ`、`ず` 等否定助动词，也是构成 `～ないでください`、`～ずに` 等句型的基础。

### 容易搞混的点

- 一类动词里，词尾是 `う` 的要变成 `わ`，比如 `買う→買わない`，不是 `買あない`；`思う→思わない` 同理。
- 有些动词虽然以 `る` 结尾，但属于一类动词，不能按二类动词直接去 `る`。比如 `帰る（かえる）→帰らない`、`切る（きる）→切らない`、`知る（しる）→知らない`、`入る（はいる）→入らない`。这类词需要单独记忆。
- 判断动词类型的小技巧：基本形词尾不是 `る` 的，基本都是一类动词；以 `る` 结尾时，看前一个假名，如果是 `い` 段或 `え` 段，大多是二类动词，但上面的例外要留意。

掌握了基本规则，要不要再看看一类动词的判断口诀或者二类动词的常见误判例子

# 什么时候使用动词基本形

在日语语法中，**动词基本形**（又称“辞书形”或“原形”，如 食べる、行く、する）的使用场景比英语更为广泛。它不仅是字典中的检索形式，还在口语和书面语中承担着重要的语法功能。

以下是必须或习惯使用动词基本形的 **7 大核心场景**：

### 1. 修饰名词（连体修饰）

这是基本形最基础的语法功能。当动词直接修饰后面的名词时，必须使用基本形（表示将来、习惯或普遍真理）。

- **日本に 行く 人**（去日本的人）→ 表示“将要去”或“经常去”
- **毎日 勉強する 習慣**（每天学习的习惯）
- ⚠️ **对比：** 如果表示“已经做了/正在做”，则需用 た形（行った人）或 て形+いる（勉強している人）。

### 2. 简体对话的肯定现在/将来时

在朋友、家人、晚辈之间的**非正式会话**中，基本形直接充当谓语，相当于敬体「～ます」的简体版。

- A: 明日、学校に 行く？（明天去学校吗？）
- B: うん、**行く**。（嗯，去。）
- A: これ、**食べる**？（吃这个吗？）
- 💡 **注意：** 此时基本形包含“现在习惯性动作”和“将来意志”两层含义，需根据语境判断。

### 3. 特定句型与文法结构

许多N4-N2级别的核心语法点要求前接动词基本形：

| 句型               | 含义      | 例句                             |
| ------------------ | --------- | -------------------------------- |
| **～ことができる** | 能够做…   | 日本語を 話す **ことができる**   |
| **～ことにする**   | 决定做…   | 日本へ 留学する **ことにした**   |
| **～つもりだ**     | 打算做…   | 来年、結婚する **つもりだ**      |
| **～ところだ**     | 正准备做… | これから 食事する **ところだ**   |
| **～前に**         | 在做…之前 | 寝る **前に**、歯を磨く          |
| **～ようにする**   | 努力做到… | 毎日 運動する **ようにしている** |
| **～はずだ**       | 理应…     | 彼はもう 着く **はずだ**         |

### 4. 引用与思考内容

在引用他人的话、自己的想法或传闻时，从句中的动词保持基本形不变（即使主句是过去时）。

- 彼は「明日 **来る**」と言った。（他说“明天来”。）
- 雨が **降る** と思う。（我觉得会下雨。）
- 母は「早く **帰れ**」と言った。（※命令/请求的引用也用原形相关形式）

### 5. 表示强烈意志或决心（书面/宣言）

在标语、歌词、诗歌或个人决意表达中，基本形可单独结句，带有强烈的意志感和未完成感。

- **絶対にあきらめない！**（绝不放弃！）
- **夢を叶える。**（实现梦想。）
- 💡 这种用法比「～ます」「～だろう」更有力量感和紧迫感。

### 6. 条件句「～なら」的前接

当使用假定条件「なら」时，前面通常接基本形（也可接其他形式，但基本形最常见）。

- 東京に **行くなら**、新幹線がいい。（如果要去东京的话，坐新干线比较好。）
- ⚠️ **区分：** 「ば」形和「たら」形需要变形（行けば／行ったら），只有「なら」可直接接基本形。

### 7. 否定形的构成基础

动词的普通体否定形「～ない」是由基本形变化而来的（五段变动词需先变未然形，一段动/カ变动词直接加ない）。

- 食べる → 食べ**ない**
- 行く → 行か**ない**
- 虽然最终形态不是基本形，但**识别和记忆动词时必须以基本形为基准**。

---

### 📌 易混淆点提醒

> **基本形 vs. ます形 vs. て形**
>
> - **基本形**：修饰名词、简体会话、接续特定语法、引用
> - **ます形**：礼貌体谓语、部分接续（ながら、たい等）
> - **て形**：连接句子、请求（てください）、进行时（ている）、许可（てもいい）

**⚠️ 初学者常见错误**
不要把所有“动词原样”都当作基本形。例如「食べ」是连用形，「行っ」是促音便，它们都不是基本形。**只有辞书中查到的完整形态（る结尾的一段动词 / う段结尾的五段动词 / する・くる）才是真正的基本形。**

掌握以上7个场景，就能覆盖日语学习和实际使用中95%以上的基本形用法。建议结合例句反复朗读，培养语感。

# 可能形

## 能形

[动词可能态学习](https://www.douban.com/note/799259698/?_i=1179572wGeBh4H)  [可能态_百度百科](https://baike.baidu.com/item/%E5%8F%AF%E8%83%BD%E6%80%81/2682958)  

日语的“可能形式”（可能形）表示“能、会、可以”做某事，比如“能吃”“能去”。它主要用来表达具备某种能力，或者客观条件允许做某事。

### 📖 变形规则

不同类别的动词，变成可能形的方法不一样，核心规则是这样的：

1. 一类动词（五段动词）：把词尾的「う」段假名变成同行「え」段假名，再加「る」。
   - 例：書く→書ける（能写）、買う→買える（能买）、飲む→飲める（能喝）、行く→行ける（能去）
2. 二类动词（一段动词）：去掉词尾的「る」，再加「られる」。
   - 例：食べる→食べられる（能吃）、見る→見られる（能看）
3. 三类动词（不规则动词）：这两个要单独记。
   - する→できる（能做）
   - 来る（くる）→来られる（こられる）（能来）

> 注意：可能动词都变成二类动词，而且前面提示宾语的助词，经常从「を」变成「が」。

### 🎯 核心用法

可能形主要有两种用法，日常和考试里都很常见：

1. 表示能力：主语本身具备做某事的能力。
   - 例：彼は日本語が話せます。（他会说日语。）
2. 表示可能性或条件允许：由于外部环境、规则、时机等客观条件，使得某事“能够”发生。
   - 例：明日、この会議に参加できます。（明天能参加这个会议。）

### 🔄 另一种表达

除了动词变形，还有一个常用的表达方式：「动词辞书形 + ことができます」，意思基本一样，也常被用来替换可能形。

- 例：私は日本語で手紙を書くことができます。（我能用日语写信。）

### ⚠️ 易混淆点

这里有两个容易搞混的词，高考也常考：

- 見える vs 見られる：「見える」强调视力或客观距离带来的“看得见”，是自然而然看到的；「見られる」强调“能去看”的可能性。
- 聞こえる vs 聞ける：「聞こえる」是声音自己传进耳朵，比如“听到声音”；「聞ける」是“能去听”，比如“能听到音乐会”。

想进一步了解日语动词变形的话，可以看看高考日语可能形考点，或者新东方在线日语网的讲解。

## 可能形属于活用还是语态

可能形在日语语法中属于“语态”（可能态），而不是“活用”本身，但它依赖动词的活用变形来实现。

日语语法体系里，==活用==指动词、形容词等词尾按语法功能发生的规则变化（如未然形、连用形、终止形、假定形、命令形）；==语态==则指通过动词变形（词尾接续助动词）来表达的可能、被动、使役、自发等语法意义。可能形（可能态）正是通过活用形加助动词构成的一种语态。

不过不同教材的划分方式有差异：《新编日语语法教程》等把活用限定为六种基本形，可能态归入语态；《新标准日本语》则直接把可能形列为十种活用形之一。

### 📌 两类动词的可能形变形规则

| 动词类别         | 变形规则                                   | 示例                             |
| ---------------- | ------------------------------------------ | -------------------------------- |
| 一类动词（五段） | 词尾う段假名变え段假名，再加「る」         | 書く→書ける、話す→話せる         |
| 二类动词（一段） | 去掉词尾「る」，加「られる」               | 食べる→食べられる、見る→見られる |
| サ变动词         | 「する」变「できる」                       | 勉強する→勉強できる              |
| カ变动词         | 「来る（くる）」变「来られる（こられる）」 | 来る→来られる                    |

### ⚠️ 两点值得注意

- 二类动词和カ变动词的可能形与被动态变形完全相同（如「食べられる」既能表“能吃”也能表“被吃”），需结合语境判断。
- 口语中常省略「ら」，如「食べれる」「来れる」，即“ら抜き言葉”，虽被视作不规范，但使用很普遍。

可能形表达三种含义：主体具备的能力、事物本身的性质、在某种条件下动作可实现的可能性。
