CSS 选择器主要分为==基础选择器、组合选择器、伪类选择器和伪元素选择器==四大类 。

### 基础选择器

1. 元素选择器：通过 HTML 标签名匹配元素，如 `p{}` 选中所有段落。
2. 类选择器：以点号开头，通过 class 属性匹配，如 `.btn{}`
3. ID 选择器：以井号开头，通过唯一 id 属性匹配，如 `header{}`
4. 通用选择器：星号 `*` 匹配所有元素。
5. 属性选择器：通过元素属性匹配，如 `[type="text"]`


### 组合选择器

1. 后代选择器：空格分隔，匹配嵌套元素，如 `div p{}`
2. 子选择器：大于号连接，仅匹配直接子元素，如 `div>p{}`
3. 相邻兄弟选择器：加号连接，匹配紧邻的下一个兄弟元素，如 `h2+p{}`
4. 通用兄弟选择器：波浪号连接，匹配后续所有兄弟元素，如 `h2~p{}`
5. 群组选择器：逗号分隔多个选择器统一应用样式。


### 伪类与伪元素选择器

1. 伪类选择器：表示元素状态，如 `:hover`（悬停）、`:focus`（焦点）、`:checked`（选中）。
2. 伪元素选择器：表示元素的部分，如 `::before`（内容前）、`::after`（内容后）、`::first-letter`（首字母）。

## html id

HTML 的 `id` 属性是给元素指定一个在整个文档中唯一的标识符，主要用来让 CSS 和 JavaScript 能精准找到并操作这个元素。

### 核心特点

- 唯一性：同一个页面里，每个 `id` 只能出现一次，不能两个元素共用。
- 用途：CSS 里用 `id名` 来写样式，JavaScript 里用 `document.getElementById()` 拿到元素。
- 大小写敏感：`myHeader` 和 `myheader` 会被当成两个不同的 `id`。
- 命名规则：至少一个字符，不能包含空格。

### 和 class 的区别

- id：唯一，一个元素一个，适合给单个特定元素用。
- class：可复用，多个元素可共用一个类名，适合批量设置样式。

### 容易踩的坑

- 别把 `id` 当 `class` 用，给一堆元素设同一个 `id`，会导致样式和脚本行为不可预期。
- 表单提交时，数据靠 `name` 属性传到服务器，光有 `id` 不行。

简单说，`id` 就像元素的身份证号，独一无二，专门用来精确定位。

## id选择器举例

id 选择器用 `#` 开头，通过元素的 `id` 属性来选中页面中唯一的那一个元素，比如 `#header { color: red; }` 就能让 `id="header"` 的元素文字变红。

### 基础写法

```html
<style>
  #intro {
    font-size: 24px;
    color: red;
  }
</style>

<p id="intro">这段文字会变成红色、24px。</p>
<p>这段不受影响。</p>
```

`#intro` 只匹配 `id="intro"` 的那个段落，其他段落不变。

### 注意几个关键点

- id 必须唯一：一个页面里 `id="intro"` 只能出现一次，不能像 `class` 那样重复用。
- 大小写敏感：HTML 里 id 是区分大小写的，`#intro` 匹配不到 `id="Intro"`。
- 优先级高：id 选择器权重高于类选择器，覆盖样式时要注意，别滥用，否则后面改样式会很麻烦。

### 派生用法

id 选择器还能配合后代选择器，只对某个区域内的元素生效：

```css
#sidebar p {
  font-style: italic;
}
```

这样只有 `id="sidebar"` 里面的段落会变斜体，其他段落不受影响。

### 什么时候用 id

适合页面里独一无二的大区块，比如页头、导航栏、页脚，或者需要 JavaScript 操作的元素；如果是按钮、卡片这类会重复的样式，优先用类选择器。

## 伪类有几种

CSS伪类没有固定的“几种”总数，标准里数量很多且不断新增，但按功能可分成几大类。伪类主要分为状态伪类、结构伪类、表单伪类、逻辑伪类、链接伪类、目标伪类等几大类。

### 核心分类

1. 状态伪类：响应元素交互状态，如 `:hover`（悬停）、`:active`（点击）、`:focus`（聚焦）、`:focus-within`（自身或子元素聚焦）。
2. 结构伪类：按元素在DOM树中的位置匹配，如 `:first-child`、`:last-child`、`:nth-child()`、`:nth-of-type()`、`:only-child`、`:empty`。
3. 表单伪类：与表单元素状态相关，如 `:checked`（选中）、`:disabled`（禁用）、`:enabled`（可用）、`:valid`（校验通过）、`:invalid`（校验失败）、`:required`（必填）。
4. 逻辑伪类：用于组合或否定选择器，如 `:not()`（排除）、`:is()`（简化列表）、`:where()`（零权重）、`:has()`（父选择器）。
5. 链接伪类：针对超链接状态，如 `:link`（未访问）、`:visited`（已访问）。
6. 其他伪类：如 `:target`（锚点目标）、`:root`（根元素）、`:lang()`（语言匹配）。

### 容易混淆的点

伪类用单冒号 `:` 开头，伪元素用双冒号 `::` 开头（如 `::before`、`::after`）。==伪类选择元素的状态或位置==，不创建新元素；==伪元素创建虚拟元素或选择元素特定部分==。

### 实用建议

- `:hover` 在移动端可能无法按预期触发，可用 `@media (hover: hover)` 适配。
- `:nth-child()` 支持公式，如 `2n` 选偶数项、`-n+3` 选前3项，做斑马纹或列表截取很方便。
- `:has()` 已得到现代浏览器广泛支持，可实现“父选择器”效果，如根据子元素状态给父容器加样式。

## 伪元素有几种

CSS伪元素的数量取决于按哪个标准来数，最常说的是4种核心伪元素，但按更完整的分类可以有5种甚至更多。

### 核心4种

这是CSS2时期就有的经典伪元素，也是面试和日常开发中最常被提到的：

1. `::before`：在元素内容的前面插入内容，需要配合 `content` 属性使用。
2. `::after`：在元素内容的后面插入内容，同样需要 `content` 属性。
3. `::first-letter`：选中块级元素的第一个字符，可做首字放大、首字下沉等效果。
4. `::first-line`：选中块级元素的第一行文本，随浏览器宽度变化而变化。

### 扩展为5种

加上 `::selection`，即用户用鼠标选中文本时的高亮样式，可自定义选中背景色和文字颜色，这是目前较公认的“5种”说法。

### 还有更多

实际开发中还会用到：

- `::placeholder`：设置表单输入框占位提示文字的样式。
- `::marker`：设置列表项前面项目符号（圆点、数字等）的样式。
- `::cue`：设置 `<audio>` 或 `<video>` 中字幕/提示文本的样式。
- `::file-selector-button`：设置文件上传按钮的样式。

> 不同资料对“有几种”的统计口径不同，取决于是否把较新或较少见的伪元素也算进去。面试中回答“4种核心 + `::selection` 共5种”是比较稳妥的答法，再补充几个扩展的会显得更全面。

`@layer` 是 CSS 的级联层（Cascade Layers）规则，用于显式声明样式层级顺序，解决大型项目中样式冲突和优先级失控问题。

### 核心作用

`@layer` 让你把样式分到不同“层”，层间优先级由声明顺序决定，而非选择器权重。后声明的层优先级更高，层内规则仍按常规特异性比较。

```css
@layer reset, base, components, utilities;

@layer reset {... }
@layer base {... }
@layer components {... }
@layer utilities {... }
```

此例优先级：`utilities` > `components` > `base` > `reset`。

### 关键规则

1. 未分层样式优先级最高：不在任何 `@layer` 内的规则，优先级高于所有命名层。
2. 层声明必须在文件顶部：遇到第一个非 `@layer` 规则后，后续层声明被忽略。
3. `!important` 反转层序：重要声明下层优先级反转，越靠后的层 `!important` 优先级越低。
4. 支持嵌套：`@layer outer { @layer inner {... } }` 等价于 `@layer outer.inner`。

### 典型场景

- 第三方库收编：将组件库样式导入指定层，避免其高特异性选择器压过业务样式。
- 主题系统：定义 `base` 和 `theme` 层，动态切换主题类，无需担心基础样式被意外覆盖。
- 替代 `!important`：通过调整层顺序控制优先级，避免滥用 `!important`。

### 注意事项

- 不是银弹：`@layer` 不改变层内选择器特异性，也不自动收编第三方样式，需配合正确导入方式使用。
- 浏览器支持：Chrome 99+、Firefox 97+、Safari 15.4+ 已支持，旧浏览器需 PostCSS 插件回退。
- 媒体查询：`@media` 必须嵌套在层内才生效，单独写会落入未命名顶层。

> 层声明位置不对或第三方样式未显式收编，`@layer` 会静默失效，样式仍按传统层叠规则计算。
