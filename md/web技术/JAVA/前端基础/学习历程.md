jQuery 是一个 JavaScript ==函数库==

> 语法

`$(selector).action()`

- 选元素 $=>$ 操作   `$("#test").hide()` ,  选取 HTML 元素，并对选取的元素执行操作
- jQuery 使用的语法是 XPath 与 CSS 选择器语法的组合   

`$` 是 jQuery 对象的别名‌：`$` 等同于 `jQuery`，调用 `$()` 即调用 jQuery 核心函数，创建并返回一个包含匹配 DOM 元素的 jQuery 对象

`selector` 是查找条件‌：语法与 CSS 选择器基本兼容，`$('p')` 选所有段落，`$('#id')` 选指定 id 元素。底层由 ==Sizzle 引擎遍历文档==，返回包装了 DOM 元素引用的 jQuery 对象（类数组结构）

> 选择器

`$("p")` : 选取所有 `<p>` 元素

`$("#test")`: `#id` 选择器

`$(".test")`: `.class` 选择器

> 事件

事件：`("p").click(function(){...});`   动作触发后执行函数         

> 方法链

一条语句中运行多个 jQuery 方法（在相同的元素上）

`$("#p1").css("color","red").slideUp(2000).slideDown(2000);`

- `"p1"` 元素首先会变为红色，然后向上滑动，再然后向下滑动

> 例子

改CSS： 

- 单个样式：`$("#box").css("color", "red");`  等价于  `element.style.color = "red"`
- 多个样式：传对象即可
